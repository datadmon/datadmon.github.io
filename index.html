Pay-per-record data APIs for India jobs, IPOs, stocks, Dubai property, UK insolvency and events

Daemon Data publishes ten data APIs as Actors on Apify Store. Each one reads a public website's own JSON endpoints or pages and returns clean records as JSON, CSV or Excel. You pay only per record returned (from $0.80 per 1,000), there is no subscription, no login to the source site and no proxy to manage, and the same input works from the Apify console, one REST call, Python, Node.js, n8n, Make, Zapier or an AI assistant through MCP.

The sources are chosen because buyers ask for them and no official API exists: India's recruiter job boards (IIMJobs, Hirist, Foundit, Instahyre), employer career sites on Oracle Recruiting Cloud, Indian IPO grey-market premium and subscription figures, NSE/BSE fundamentals via Tickertape, the Dubai Land Department transaction register, The Gazette's UK insolvency notices and Luma's event calendars.

Every page on this site states when its numbers were measured. The Apify listing of each API is the canonical description; these pages add the context, comparisons and questions that the listings leave out.
