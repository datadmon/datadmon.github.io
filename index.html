Data APIs and free research tools from Daemon Data

Daemon Data publishes 33 public Actors on Apify Store: 31 with per-record pricing and 2 tools with no fee of their own (downstream board Actor charges apply). This count is generated from the live Apify API at build time and excludes private projects. The data Actors read public JSON endpoints or pages and return JSON, CSV or Excel. Call them from Apify, REST, Python, Node.js, n8n, Make, Zapier or an AI assistant through MCP. No login to the source site or proxy setup is needed on your side.

Dubai Property Data API

Dubai Property Data API: registered DLD sales, Ejari rent contracts and the DLD project register as JSON or CSV, billed per row ($0.001 per transaction or rent row, $0.005 per project). One cost table for sample, monthly backfill and daily-feed jobs, and free sample files (500 newest sales, 500 newest rent contracts, all 601 active projects) with no form or account.

Free IPO GMP accuracy tool

IPO GMP vs listing gain explorer compares the last reported pre-listing GMP with actual opening gains for 2026 Indian listings. Filter mainboard or SME, issue size and GMP band; see accuracy statistics and download the complete dated CSV or JSON without signing up.

Sources include Naukri, IIMJobs, Hirist and other Indian boards; Get on Board in Latin America, Gupy in Brazil, OnlineJobs.ph and Welcome to the Jungle; five employer ATS platforms and Oracle Recruiting Cloud; Indian IPOs and stocks; property, trade, company and insolvency registers; and Luma events. India Jobs Feed and India Jobs MCP provide one route across ten Indian boards.

Every page on this site states when its numbers were measured. The Apify listing of each API is the canonical description; these pages add the context, comparisons and questions that the listings leave out.

Ready-to-fork templates

Three open-source GitHub Actions templates run these APIs on a schedule from your own repository: India job alerts (new IIMJobs, Hirist, Foundit and Instahyre jobs every morning to Slack, Telegram, Discord or a GitHub issue), UK insolvency monitor (alerts when a watchlist company appears in The Gazette) and India IPO GMP tracker (daily GMP table and history with Telegram alerts).
