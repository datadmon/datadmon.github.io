Dubai real estate projects register (DLD) as JSON API

Dubai Real Estate Projects API is a pay-per-record Apify Actor by Daemon Data that returns Registered Dubai real estate projects from the official Dubai Land Department register: developer, status, project value, escrow account, % completed, units, area, dates. Plus the DLD registered-developers list with licence dates. $5 per 1,000 records. as JSON, CSV or Excel. It costs $0.005 per project record with the default options ($5.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Checked on 9 Nov 2026

The DLD register held 915 projects worth AED 212 billion (323,000 units): 601 active, 114 pending approval, 180 finished in 2026, 14 cancelled. Escrow account numbers on 803 of them. DLD approved 15-30 projects a month in 2026; most projects by developer: Binghatti 37, Emaar 29, Azizi 17. A full-register run returns all 915 rows in about 20 seconds.

Why teams use it

  • The complete register in one run. DLD's open-data page shows the projects whose chosen date (start, planned end, approval or completion) falls in the current year, and the four views overlap only partly (401, 323, 280 and 171 rows). The Actor reads all four and merges them by project number, so a finished project keeps its completion date and an active one its approval date: 915 projects instead of 401.
  • Escrow account numbers. Every active project carries the escrow account registered with DLD (803 of 915 rows). Off-plan payments in Dubai must go to this account; check it before paying a developer.
  • Change feed. With onlyNew a project is delivered once, and again only when its status, construction progress, completion date, planned end, value, unit count or escrow account changes, labelled changeType: "new" or "updated". Unchanged projects are not charged.
  • Community names work. DLD uses official area names ("Madinat Al Mataar", "Al Barsha South Fourth"); this Actor also accepts Dubai South, Expo City, JVC, JVT, JLT, Dubai Marina, Downtown, Dubai Hills, Dubai Islands, Business Bay, Creek Harbour, Sports City, Motor City, Damac Hills, Arjan, Town Square and more.
  • Value per dwelling. valuePerUnitAed divides the declared value by apartments plus villas (not by land plots), a quick sanity check against launch prices.
  • Open data, business data only. Project and developer records as DLD publishes them; no buyer or owner data.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-10; this build does not run paid example searches.

{
  "status": "active",
  "maxItems": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~dubai-real-estate-projects/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"status": "active", "maxItems": 50}'

Python: ApifyClient(token).actor("data_daemon/dubai-real-estate-projects").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/dubai-real-estate-projects with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
datasetstringWhich DLD register to read. projects (default): every project DLD currently publishes, i.e. whose start, planned end, approval or completion date falls in the current year (915 projects on 9 Nov 2026, AED 212 billion, 323,000 units). developers: developers registered with DLD this year (215). Older years are not served by the DLD open-data gateway.
statusstringProjects only. active (default) = approved projects with an escrow account, approval date and construction progress; pending = newly registered projects awaiting approval (the earliest signal of a launch); finished = completed this year; all = everything incl. cancelled. On 9 Nov 2026: 601 active, 114 pending, 180 finished, 14 cancelled, 6 conditional.
fromDatestringOptional. Start of a date range (included), YYYY-MM-DD, applied to Date type (projects) or the registration date (developers). Leave all date fields empty to read the whole current register.
toDatestringOptional. End of the range (included), YYYY-MM-DD. Defaults to today when From date or Days back is set.
daysBackintegerOptional. Instead of From date: the last N days up to To date (or today), both ends included. E.g. 30 with Date type adoptionDate gives the projects DLD approved in the last month (about 15-25 per month in 2026).
dateTypestringProjects only; which project date the range applies to. Ignored when no date range is given.
areasarrayProjects only. Official DLD area names or community names, e.g. Madinat Al Mataar (Dubai South), Palm Deira (Dubai Islands), Al Barsha South Fourth (JVC), Business Bay, Wadi Al Safa 5. Each area is fetched with its own query. Leave empty for all of Dubai. Unknown names are skipped with a suggestion in the run status.
developersarrayKeep only records whose developer name contains one of these texts (case-insensitive), e.g. Emaar, Binghatti, Damac, Sobha. Works for both registers. Filtered-out rows are not charged.
minProjectValueAedintegerProjects only. Keep projects whose declared value is at least this amount, e.g. 500000000 for AED 500 million and above. Filtered-out rows are not charged.
sortstringDLD numbers projects and developers in registration order, so newestFirst with Max items returns the latest registrations.
includeArabicbooleanAdd an arabic object with the Arabic project, developer, area and zone names.
maxItemsintegerMaximum records to save (0 = the whole register). Each saved record is one charged event; the default of 50 keeps a first try at about $0.25.
onlyNewbooleanFor scheduled runs: deliver (and charge) a project only when it is new to this State name or when its status, % completed, completion date, end date, value, unit count or escrow account changed since the last delivery. Each row then carries changeType (new or updated). Memory lasts 400 days.
stateNamestringName of the only-new memory. Use a different name for each independent feed.

Price

$0.005 per project record ($5.00 per 1,000); $0.005 per developer record ($5.00 per 1,000). List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.

Apify's free plan includes $5 of usage a month, about 1,000 project records before start fees; the Actor's own compute is included in the per-record price, and records skipped by filters, de-duplication or only-new mode are not charged.
