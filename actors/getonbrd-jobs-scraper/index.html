Get on Board LATAM jobs API with salary & only-new feeds

Get on Board Jobs Scraper is a pay-per-record Apify Actor by Daemon Data that returns LATAM tech jobs with monthly USD salary, full descriptions, country eligibility and persistent only-new feeds as JSON, CSV or Excel. It costs $0.0008 per job with full description with the default options ($0.80 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-14; this build does not run paid example searches.

{
  "categories": [
    "programming"
  ],
  "remoteOnly": true,
  "minSalaryUsd": 1000,
  "maxItems": 20
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~getonbrd-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categories": ["programming"], "remoteOnly": true, "minSalaryUsd": 1000, "maxItems": 20}'

Python: ApifyClient(token).actor("data_daemon/getonbrd-jobs-scraper").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/getonbrd-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

What it is not for

Candidate profiles; worldwide remote eligibility inferred from the remote flag; annual or original local-currency salary. The data belongs to its publisher; the Actor reads public pages and endpoints and leaves out personal contact details.

Questions buyers ask

Is salary monthly USD or yearly pay?

The public API's numeric bands are USD per month. The Actor preserves those figures without annualizing them. Employer prose may also mention local-currency compensation; it remains in the description and is not substituted into the salary object. Undisclosed salary stays null.

Does remote mean I can apply from any country?

No. remote_local restricts remote work geographically. Even for fully remote listings, use the source's countries field and the original job page to check eligibility. Country filtering never substitutes the employer's headquarters country.

¿Puedo exportar empleos remotos de Get on Board con sueldo?

Sí. Usa remoteOnly: true, countries: ["CL"] (o tu país) y minSalaryUsd. Exporta empleos de tecnología en JSON, CSV o Excel, con descripción, empresa, seniority y sueldo en USD mensuales. onlyNew: true y el mismo stateName omiten empleos ya entregados sin volver a cobrar por ellos.

Posso extrair vagas remotas do Get on Board para o Brasil?

Sim. Use countries: ["BR"] e remoteOnly: true. O filtro respeita os países elegíveis informados pela vaga; remoto não significa aceitação de candidatos do mundo inteiro. A remuneração estruturada é em USD por mês. O modo onlyNew evita cobrar novamente por vagas já entregues no mesmo feed.

Why did a repeat run return more jobs, or no jobs?

The first run may have hit its cap, leaving unseen older jobs for a later run. Once the matching source inventory is exhausted, later runs return zero until new IDs appear. A refreshed existing ID is still considered delivered. See Run summary for skipped counts and stop reasons.

Is this an official Get on Board integration?

This is an independent Actor using public pages and public JSON, with no login or private candidate data. Get on Board publishes its own API; this Actor adds Apify exports, filters, billing and persistent delivered-ID memory. Follow applicable law and source usage conditions for your intended use. Source availability and fields can change.

How do I report a problem?

Open the Issues tab with your input and run ID, without credentials. Custom extraction and integration requests can be discussed there.
