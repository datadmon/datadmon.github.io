UK insolvency notices: pay-per-record data API

UK Gazette Insolvency Notices Scraper – Winding-Up Petitions is a pay-per-record data API on Apify that returns winding-up petitions, administrations, liquidations from The Gazette as JSON, CSV or Excel. It costs $0.002 per notice ($2.00 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

Run it on Apify   Listing as plain text for agents

What you get

A daily feed of UK companies entering insolvency, structured for prospecting and risk screening. The Gazette is where every winding-up petition, administration, liquidation and creditors' meeting must be published. This Actor reads its notice feed and each notice's linked-data record and returns the company name and number, registered office and trading address, postcode, nature of business (the SIC description stated in the notice), who presented the petition (for example HMRC, with a ready-made petitionerIsHmrc flag), court and case number, hearing date and the deadline to appear, and the insolvency practitioner's or solicitor's name, firm, email and phone.

Why use it

  • Structured, joinable fields. Company number for Companies House, postcode, nature of business, petitioner, court, case number, practitioner firm. No copy-pasting notice text.
  • Earlier than Companies House. Petitions are advertised before the hearing; the company record often changes weeks later.
  • Any notice type, any date range. Petitions, winding-up orders, administrations, liquidator appointments, creditors' meetings, bankruptcy orders, or personal insolvency.
  • Built for schedules. publishedWithinDays gives a rolling window, onlyNewSinceLastRun delivers only notices you have not received before, and skipped notices are never charged.
  • Open Government Licence. Gazette notices are Crown copyright under OGL v3.0; company-level data can be reused with attribution (see "Licence and personal data" below).
  • From an AI assistant:* add the MCP connector https://mcp.apify.com/?tools=data_daemon/uk-gazette-insolvency-notices in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~uk-gazette-insolvency-notices/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"noticeTypes": ["2450"], "includeLinkedData": true, "maxItems": 40}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/uk-gazette-insolvency-notices with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/uk-gazette-insolvency-notices.py, node/uk-gazette-insolvency-notices.mjs, n8n/uk-gazette-insolvency-notices.json.

Input fields

FieldTypeMeaning
servicestringWhich Gazette search to query. Default insolvency.
noticeTypesarrayOptional Gazette notice type codes (verified Oct 2026): 2450 petitions to wind up (companies), 2451 petitions to wind up (partnerships), 2452 winding-up orders, 2441 resolutions for winding up, 2432 and 2443 appointment of liquidators, 2442 meetings of creditors, 2433 notices to creditors, 2410 appointment of administrators, 2503 bankruptcy orders. Default is petitions and administrations (2450, 2410); pass an empty list for every type in the section.
categoryCodestringOptional Gazette category code, e.g. G205000000 corporate insolvency, G206000000 personal insolvency, G205010000 companies.
textstringOptional free-text search, e.g. Revenue and Customs for HMRC petitions, a company name, a town, or an insolvency practitioner firm.
publishedWithinDaysintegerRelative date window for schedules: only notices published in the last N days, counted back from today (UTC). 1 = since yesterday, 7 = the last week. Ignored when Published from is set. Combine with Only new notices for a daily feed.
startPublishDatestringYYYY-MM-DD. Only notices published on or after this date. Leave empty to use Published within the last N days instead.
endPublishDatestringYYYY-MM-DD. Only notices published on or before this date.
sortBystringSort order. Default latest-date.
includeLinkedDatabooleanFetch each notice's linked-data record and add it as top-level fields: company number, registered office and trading address, postcode, nature of business, petitioner (and an HMRC flag), court and case number, hearing, petition, appointment and resolution dates, and the insolvency practitioner's name, firm, IP number and contact details. Charged as one extra notice-details event per notice where the record was retrieved. Default on.
onlyNewSinceLastRunbooleanDeliver only notices that an earlier run with the same search (or the same State key) has not already delivered. Skipped notices are not charged. Delivered notice ids are remembered for 180 days in a key-value store named uk-gazette-notices-state in your account. Made for daily schedules.
stateNamestringOptional name for this saved search's memory when Only new notices is on. Leave empty to derive it from the section, notice types, category and search text. Use a different key to track several feeds separately.
maxItemsintegerStop after this many notices have been delivered. Default 40, about $0.20 with structured details at FREE prices.

Questions and answers

How much does it cost to monitor UK winding-up petitions?

$0.002 per notice plus $0.003 for the structured details record. About 140 petitions a week means roughly $3 a month for a daily feed with details.

Does it return only new notices?

Yes. Turn on onlyNewSinceLastRun; each run delivers only notices that earlier runs with the same search have not delivered, and the skipped ones are free.

Can I reuse the data commercially?

Gazette notices are Crown copyright under the Open Government Licence v3.0, so company-level data can be reused with attribution. Personal data is excluded from the licence.

Which notice types are supported?

Any Gazette notice type code. The common corporate ones are 2450 petitions to wind up, 2452 winding-up orders, 2410 appointment of administrators, 2441 resolutions for winding up, 2432 and 2443 appointment of liquidators, 2442 meetings of creditors and 2433 notices to creditors.

Do I need a proxy or login?

No. If The Gazette rate-limits the structured-data requests, the Actor switches to Apify datacenter proxy by itself.
