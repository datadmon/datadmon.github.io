UK Gazette insolvency notices as JSON feed

UK Gazette Insolvency Notices Scraper is a pay-per-record Apify Actor by Daemon Data that returns winding-up petitions, administrations, liquidations from The Gazette as JSON, CSV or Excel. It costs $0.005 per notice with the default options ($5.00 per 1,000); no login to the source site, no proxy, no browser, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Why teams use it

  • Structured, joinable fields. Company number for Companies House, postcode, nature of business, petitioner, court, case number, practitioner firm. No copy-pasting notice text.
  • Earlier than Companies House. Petitions are advertised before the hearing; the company record often changes weeks later.
  • Any notice type, any date range. Petitions, winding-up orders, administrations, liquidator appointments, creditors' meetings, bankruptcy orders, or personal insolvency.
  • Built for schedules. publishedWithinDays gives a rolling window, onlyNewSinceLastRun delivers only notices you have not received before, and skipped notices are never charged.
  • Open Government Licence. Gazette notices are Crown copyright under OGL v3.0; company-level data can be reused with attribution (see "Licence and personal data" below).
  • From an AI assistant:* add the MCP connector https://mcp.apify.com/?tools=data_daemon/uk-gazette-insolvency-notices in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

Input and how to call it

A verified example input (it returned data on 2026-10-27):

{
  "noticeTypes": [
    "2450"
  ],
  "includeLinkedData": true,
  "maxItems": 40
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~uk-gazette-insolvency-notices/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"noticeTypes": ["2450"], "includeLinkedData": true, "maxItems": 40}'

What it is not for

Companies House filings; Scottish/Irish court records outside The Gazette. The data belongs to its publisher; the Actor reads public pages and endpoints and leaves out personal contact details.

Questions buyers ask

How much does it cost to monitor UK winding-up petitions?

$0.002 per notice plus $0.003 for the structured details record. About 140 petitions a week means roughly $3 a month for a daily feed with details.

Does it return only new notices?

Yes. Turn on onlyNewSinceLastRun; each run delivers only notices that earlier runs with the same search have not delivered, and the skipped ones are free.

Can I reuse the data commercially?

Gazette notices are Crown copyright under the Open Government Licence v3.0, so company-level data can be reused with attribution. Personal data is excluded from the licence.

Which notice types are supported?

Any Gazette notice type code. The common corporate ones are 2450 petitions to wind up, 2452 winding-up orders, 2410 appointment of administrators, 2441 resolutions for winding up, 2432 and 2443 appointment of liquidators, 2442 meetings of creditors and 2433 notices to creditors.

Do I need a proxy or login?

No. If The Gazette rate-limits the structured-data requests, the Actor switches to Apify datacenter proxy by itself.
