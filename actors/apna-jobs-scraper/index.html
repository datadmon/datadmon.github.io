Apna (apna.co) jobs with salaries as JSON API

Apna Jobs Scraper is a pay-per-record Apify Actor by Daemon Data that returns Apna (apna.co) India jobs with salary, locality, department, work mode and full descriptions; full-board export as JSON, CSV or Excel. It costs $0.0008 per job with the default options ($0.80 per 1,000); no login to the source site, no proxy, no browser, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

A verified example input (it returned data on 2026-10-31):

{
  "cities": [
    "Pune"
  ],
  "departments": [
    "Delivery / Driver / Logistics"
  ],
  "postedWithin": "7d",
  "maxJobsPerSearch": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~apna-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cities": ["Pune"], "departments": ["Delivery / Driver / Logistics"], "postedWithin": "7d", "maxJobsPerSearch": 50}'

Python: ApifyClient(token).actor("data_daemon/apna-jobs-scraper").call(run_input=...), full file python/apna-jobs-scraper.py. Node.js: node/apna-jobs-scraper.mjs. n8n: importable workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/apna-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
searchTermsarrayJob titles or skills, e.g. telecaller, delivery boy, accountant, python developer, driver. One Apna search per keyword; Apna returns at most 500 jobs per keyword. Leave empty for the latest jobs, filtered by city, department and the options below.
allJobsbooleanIgnore the keywords and export every open Apna job, department by department (about 71,000 of the 76,800 open jobs on 26 Oct 2026 carry a department). Combine with Only new jobs since the last run for a daily feed, or with cities / departments to export a slice. Large: set a maximum cost per run.
citiesarrayCity names, e.g. Mumbai, Delhi, Bangalore, Hyderabad, Pune, Chennai, Kolkata, Ahmedabad, Jaipur, Lucknow. Apna filters by 74 cities; Delhi, Gurgaon, Noida and Ghaziabad all map to Delhi-NCR. Other place names are matched against each job's location. remote means work from home.
departmentsarrayApna departments, e.g. Sales & BD, Customer Support, Delivery / Driver / Logistics, Software Engineering, Finance & Accounting, Healthcare / Doctor / Hospital Staff, Banking / Insurance / Financial Services. A word such as sales, delivery or healthcare picks the matching department. Applies to runs without keywords.
workModesarrayOnly jobs with these work modes. Empty = any.
workTypestringOnly full-time or only part-time jobs.
shiftstringOnly day-shift or only night-shift jobs.
educationstringJobs open to candidates with this highest education, as Apna filters them.
englishLevelstringJobs open to candidates with this English level, as Apna filters them.
postedWithinstringOnly jobs posted or refreshed by the employer recently (Apna's own windows; a refreshed job keeps its original postedAt). Last 24 hours with All jobs is a daily board-wide feed of about 2,000 jobs on an average day.
includeDescriptionbooleanFull job description as plain text. Keyword searches fetch each job page for it (slower); the feed already carries it. Price is the same either way.
maxJobsPerSearchintegerCap for each keyword (or each city / department listing). 0 = no cap. Not used with All jobs.
maxJobsintegerStop after this many saved jobs. 0 or empty = no total cap (the run's maximum cost still applies).
onlyNewSinceLastRunbooleanFor schedules: remember delivered job ids (in a named key-value store in your account) and save only jobs that earlier runs with the same settings did not deliver. Skipped jobs are not charged.
stateNamestringName of the only-new memory. Empty = derived from the keywords and filters. Give two schedules the same name to share one memory.
skipJobIdsarrayApna job ids you already have (the id field). They are neither saved nor charged.

Questions buyers ask

Is there an official Apna API?

Not a public one. This Actor reads the public JSON job feed and job pages that the apna.co website loads. It exposes them as a REST API with schedules, webhooks and only-new runs.

Does it return candidates or recruiter contacts?

No. It returns job listings only: no candidate data, and no recruiter names, phone numbers or e-mail addresses.

Why do some jobs have no salary?

The employer did not disclose it, or the job is an external listing applied for on the employer's own career site.

Do I need a proxy or login?

No.
