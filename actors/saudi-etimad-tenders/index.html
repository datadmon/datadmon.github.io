Saudi Etimad government tenders and awards as JSON feed

Saudi Etimad Tenders API is a pay-per-record Apify Actor by Daemon Data that returns Saudi government tenders from the Etimad procurement portal as JSON: agency, type, activity, region, Gregorian and Hijri deadlines, document fee, status, plus detail pages with award results (bidders, winner, amount). Keyword, agency, activity and region filters; daily only-new feed. $3 per 1,000. as JSON, CSV or Excel. It costs $0.003 per tender record with the default options ($3.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Checked on 9 Nov 2026

The Etimad portal listed 291,416 tenders in total. On 9 Nov 2026 the last-two-days example returned 183 new tenders (about 90 a day) with agency, activity, region, type, deadlines and document fee; a {} run returns the 50 newest in about 10 seconds. Awarded tenders add bidders, the awarded supplier and the award value.

Why teams use it

  • A feed, not a search form. The portal shows 24 tenders a page in Arabic and has no RSS, export or API for suppliers without an account. This Actor returns the newest tenders first as clean rows and remembers what it delivered, so a scheduled run gives you only new or changed tenders (onlyNew), never charged twice.
  • Searchable in English. Tender type, status, region and the main activity groups come with English translations next to the Arabic originals (tenderTypeEn, statusEn, regionEn), and filters accept English names (regions: ["Riyadh"], activities: ["IT"], tenderTypes: ["public"]). Tender names, agencies and purposes stay exactly as the agency published them (Arabic, sometimes English).
  • Award results with prices. With includeDetails, awarded tenders carry every bidder's financial offer and technical result, the awarded supplier and the award value: the data a competitor analysis needs.
  • Both calendars. Deadlines come as Gregorian timestamps (submissionDeadline) and Hijri dates (submissionDeadlineHijri), plus daysRemaining.
  • Built for schedules. Publication windows (2 days to 90 days), a run-deadline guard, a charge-limit guard and a clear status message; unchanged tenders in only-new mode are skipped and not charged.
  • Business data only. Agencies, tenders and supplier companies as published on the public portal. No login, no personal data.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-09; this build does not run paid example searches.

{
  "publishedWithin": "2d",
  "maxItems": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~saudi-etimad-tenders/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"publishedWithin": "2d", "maxItems": 50}'

Python: ApifyClient(token).actor("data_daemon/saudi-etimad-tenders").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/saudi-etimad-tenders with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
stagestringWhich tenders to list, as the Etimad visitor portal groups them. all (default) returns every published tender newest first (291,000 on 9 Nov 2026); open the ones still accepting offers (about 1,300); awarded the ones whose award results are published (combine with Published within 90 days and Include details for an awards feed with supplier names and amounts).
publishedWithinstringThe portal's own publication-date window. On 9 Nov 2026: 182 tenders in the last 2 days, 707 in the last week, 2,800 in the last month, 7,200 in the last 3 months. Use 2d for a daily feed.
fromDatestringOptional exact publication date range start (included), YYYY-MM-DD. The listing is read newest first and stops once it reaches older tenders. Combine with Published within = any for a backfill.
toDatestringOptional publication date range end (included), YYYY-MM-DD.
keywordsarraySearch terms, Arabic or English, matched by Etimad's own search over tender name, number and agency, e.g. صيانة, تكييف, software, CCTV. One listing query per keyword; results are merged and de-duplicated.
agenciesarrayAgency names (Arabic, as Etimad lists them, e.g. وزارة الصحة, أمانة منطقة الرياض) or 12-digit Etimad agency codes. A name is matched against the portal's agency list (up to 8 matching agencies are queried); names with more matches filter the rows by agency/branch name instead.
activitiesarrayTender activity: main activity id 1-19 or its English/Arabic name (contracting, IT, healthcare, maintenance, security, consulting, transport...), or an Etimad sub-activity id such as 601 (electricity, gas, water and HVAC supplies). One query per activity.
tenderTypesarraypublic (منافسة عامة), directPurchase (شراء مباشر), framework (اتفاقية إطارية), largeCompanies, reverseAuction, twoStage, postQualification, competition, revenueShare. Empty = all types.
regionsarrayExecution region: Riyadh, Makkah, Madinah, Qassim, Eastern Province, Asir, Tabuk, Hail, Northern Borders, Jazan, Najran, Al Bahah, Al Jouf (English, Arabic or id 1-13). Empty = all of Saudi Arabia.
documentFeestringPrice of the tender documents (booklet), a proxy for contract size. The portal answers this filter slowly (10-30 s per page).
includeDetailsbooleanAlso read each tender's public detail page: purpose, contract duration, insurance and guarantee requirements, submission method, contractor classification, execution region and city, activities, expected award and work-start dates, and the published award results (bidders with offer amounts, awarded supplier and award value). Adds one tender-details event per tender (4 requests each, about 1-2 s per tender).
maxItemsintegerMaximum tenders to save, newest first (0 = everything that matches). Each saved tender is one charged event; the default of 50 keeps a first try at about $0.15 ($0.50 with details).
onlyNewbooleanFor scheduled runs: deliver (and charge) a tender only when it is new to this State name or when its status, submission deadline, enquiry deadline, opening date or name changed since the last delivery. Each row then carries changeType (new or updated). Memory lasts 400 days.
stateNamestringName of the only-new memory. Use a different name for each independent feed.

Price

$0.003 per tender record ($3.00 per 1,000); $0.007 per tender details and award results ($7.00 per 1,000). List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.

Apify's free plan includes $5 of usage a month, about 1,666 tender records before start fees; the Actor's own compute is included in the per-record price, and records skipped by filters, de-duplication or only-new mode are not charged.
