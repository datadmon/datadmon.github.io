Dubai Ejari rent contracts (DLD) as JSON API

Dubai Rent Contracts API is a pay-per-record Apify Actor by Daemon Data that returns registered Dubai rent contracts (Ejari) from the official Dubai Land Department register: annual rent, contract value, size, rent per sqm, area, project, property type, new vs renewed and lease dates (signed leases, not asking rents) as JSON, CSV or Excel. It costs $0.001 per rent contract row with the default options ($1.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Checked on 8 Nov 2026

From 1 to 6 Nov 2026 Ejari registered 19,436 rent contracts (24,631 unit rows: 392 multi-unit contracts repeat their full amount on 5,587 rows). Of the 19,044 single-unit contracts, 53% were renewals and 76% residential. The median annual rent of 12,988 single-unit residential flats was AED 64,240; Marsa Dubai (Dubai Marina) AED 115,000 and Business Bay AED 90,000.

Why teams use it

  • Registered rents. Every Ejari contract, not a sample of listings. New leases and renewals are both included and labelled.
  • No double counting. DLD lists a contract that covers several units (a building, a labour camp) as one row per unit, and each row repeats the whole contract's rent. In the first week of November 2026, 392 such contracts produced 5,587 rows, one of them with 482 rows of AED 4,033,177.50 each. Summing those rows would add about AED 1.9 billion of rent for that one contract. Every row here carries unitsInContract, annualRentPerSqmAed is only computed when rent and size describe the same thing, and One row per contract merges them (you then pay per contract).
  • Community names work. DLD uses official area names ("Marsa Dubai", "Al Barsha South Fourth"); this Actor also accepts Dubai Marina, JBR, Downtown, JVC, JVT, JLT, Dubai Hills, Sports City, Motor City, Damac Hills, Discovery Gardens, Al Furjan, International City, Silicon Oasis, Arjan, Town Square, Creek Harbour and Dubai South. A name like "Al Barsha" includes its numbered sub-areas.
  • Complete paging. Rows come sorted by registration time; the rows of one contract always arrive together, so nothing is repeated or lost between pages. Checked against day-by-day pulls: 24,631 of 24,631 rows, 0 extra, 0 missing.
  • Open data, no personal data. No tenant or landlord names, no contract numbers.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-12; this build does not run paid example searches.

{
  "daysBack": 7,
  "areas": [
    "Business Bay",
    "Dubai Marina"
  ],
  "propertySubTypes": [
    "Flat"
  ],
  "maxItems": 200
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~dubai-rent-contracts/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"daysBack": 7, "areas": ["Business Bay", "Dubai Marina"], "propertySubTypes": ["Flat"], "maxItems": 200}'

Python: ApifyClient(token).actor("data_daemon/dubai-rent-contracts").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/dubai-rent-contracts with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
fromDatestringStart of the range (included), YYYY-MM-DD (DD/MM/YYYY also accepted), matched against the date chosen in Date type (registration date by default). Leave empty to use Days back instead, so a scheduled run never needs a date edit.
toDatestringEnd of the range (included), YYYY-MM-DD. Defaults to today (UTC).
daysBackintegerUsed when From date is empty: the last N days up to To date (or today), both ends included, so N=1 covers yesterday and today. Default 7. Dubai registers about 5,000 rent contract rows per working day (about 25,000-30,000 a week, Nov 2026). For a daily scheduled feed use 2 with Only new contracts on.
dateTypestringWhich contract date the range applies to. registrationDate (default) gives a clean daily feed of newly registered contracts; startDate finds leases starting in the range; endDate finds leases expiring in the range (renewal and churn prospecting).
contractVersionstringFilter by Ejari contract version. About 45% of registrations are new leases and 55% renewals (Nov 2026).
usagestringFilter by property usage: about 76% residential, 23% commercial (Nov 2026).
freeholdstringFreehold areas are where foreigners can own property (Dubai Marina, Downtown, JVC...).
areasarrayOfficial DLD area names, e.g. Business Bay, Al Barsha South Fourth, Marsa Dubai (Dubai Marina), Burj Khalifa (Downtown). Each area is fetched with its own query. Leave empty for all of Dubai. Unknown names are skipped with a suggestion in the run status.
propertySubTypesarrayKeep only these sub-types, e.g. Flat, Villa, Office, Shop, Warehouse, Labor Camps, Hotel apartments. Leave empty for all. Filtered-out rows are not charged.
oneRowPerContractbooleanDLD lists a contract that covers several units (a building, a labour camp) as one row per unit, and every row repeats the whole contract's amount. On: such contracts are merged into one row with unitsInContract, the total sizeSqm and the sub-types, so rent totals are not inflated and you pay per contract (Nov 1-6 2026: 24,631 rows = 19,436 contracts). Off (default): one row per unit, as DLD publishes it.
sortstringOrder by registration time. With Max items set, newestFirst returns the latest contracts.
includeArabicbooleanAdd an arabic object with the Arabic area, project, property type and landmark names.
maxItemsintegerMaximum rows to save (0 = everything in range). Each saved row is one charged event; the default of 200 keeps a first try cheap.
onlyNewbooleanFor scheduled runs: skip (and do not charge) rows that an earlier only-new run with the same State name and filters already delivered. Memory lasts 120 days.
stateNamestringName of the only-new memory. Use a different name for each independent feed.
