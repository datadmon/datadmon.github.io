Instahyre jobs: pay-per-record data API

Instahyre Jobs Scraper is a pay-per-record data API on Apify that returns India tech jobs from product companies and startups by skill, city, experience and company size, full descriptions included as JSON, CSV or Excel. It costs $0.0008 per job ($0.80 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

Live check

Live check, 21 Oct 2026: python matched 4,300 open Instahyre jobs (2,600 in Bangalore), react 1,600, data science 8,000 (title and skill-tag matching is broad), devops work-from-home 134. A 50-job run with descriptions takes well under a minute on the Apify platform and costs $0.04 plus the $0.001 start fee.

What you get

Turn Instahyre into a clean, scheduled feed of India tech jobs. Instahyre is the hiring platform Indian product companies and startups use for engineering, data, product and design roles: about 12,700 open tech jobs (counted 21 Oct 2026), 6,800 of them in Bangalore, 1,700 in Gurgaon, 1,200 in Hyderabad and 1,100 work-from-home, posted by employers from 10-person startups to Accenture and Amazon. This Actor searches Instahyre by skill or role, city, experience, company and company size and returns one JSON row per job with the full job description (HTML + plain text), experience range, skills, job functions, posting date, the company profile (headcount, founding year, tagline, website, logo) and the job URL.

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~instahyre-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["python"], "locations": ["Bangalore"], "companySizes": ["small", "medium"], "includeDescription": true, "maxJobsPerQuery": 50}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/instahyre-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/instahyre-jobs-scraper.py, node/instahyre-jobs-scraper.mjs, n8n/instahyre-jobs-scraper.json.

Input fields

FieldTypeMeaning
queriesarrayOne Instahyre search per item, matched against job titles and skill tags, e.g. python, react, data science, devops, product management, java developer. Put cities in locations. A job found by two keywords is saved and charged once. Leave the list with one item for a quick first run.
locationsarrayOptional. Cities as Instahyre lists them: Bangalore, Mumbai, Delhi, Gurgaon, Noida, Hyderabad, Chennai, Pune, Kolkata, Ahmedabad, or Work From Home for remote roles; regions such as South India and about 300 smaller cities also work. Several cities = any of them. Common alternative spellings (Bengaluru, Gurugram, Bombay, Remote) are mapped; an unknown name is ignored with a note in the status message. Leave empty for all of India.
minExperienceintegerOnly jobs whose stated experience range reaches at least this many years (0-30). Checked on each job page; jobs that state no range are kept.
maxExperienceintegerOnly jobs whose stated experience range starts at or below this many years (0-30). 1 or 2 is a good early-career filter.
experienceYearsintegerInstahyre's own experience filter: only jobs open to a candidate with exactly this many years (the job's range must cover it). Applied by the site before anything is fetched, so it is the cheapest way to narrow a search; combine with minExperience/maxExperience for a band.
postedWithinDaysintegerOnly jobs posted in the last N days (1-365). Instahyre keeps jobs open for months and its search has no date filter, so the Actor reads the posting date from each job page and leaves out older jobs without charging. In only-new mode the jobs that are left out are remembered too, so later runs do not re-check them.
companySizesarrayOptional. Any of small (under 100 employees), medium (100-1,000) and large (over 1,000). Several values = any of them. Applied by the site.
jobTypestringall (default), full-time or internship. Applied by the site.
companiesarrayOptional. Only jobs posted by these companies, e.g. Amazon, Deutsche Telekom Digital Labs. Several names = any of them. Applied by the site; combine with an empty keyword list to watch everything a company posts.
includeDescriptionbooleanOn (default): one extra request per job reads the public job page and adds the full description (HTML and plain text), posting date, experience range, employment type, job functions and the company website. The price per job is the same either way. Off: listing fields only (title, company profile, cities, skills, URL), about three times as fast, enough for counting jobs or sizing a market.
maxJobsPerQueryintegerStop a keyword after this many new jobs (default 50). Cost: $0.0008 per job with its description, so 50 jobs = $0.04. Raise it for full exports: python alone matches about 4,300 open jobs and the site serves 35 per page.
maxJobsintegerHard cap on saved jobs for the whole run across all keywords (0 = no cap).
onlyNewSinceLastRunbooleanOn: deliver only jobs that an earlier run with the same stateName has not already delivered, and skip the rest without charging. Set maxJobsPerQuery high enough for the first run to take the whole result list (or add postedWithinDays), so later runs really return only new postings. Off (default): return every matching job.
stateNamestringOptional name for this search's memory when onlyNewSinceLastRun is on, e.g. python-bangalore-daily. Leave empty to derive it from the keywords, cities and filters. Use a new name to start over.
skipJobIdsarrayArray of job IDs you already have (the id field from earlier runs), e.g. ["424473", "441980"]. They are skipped before any page fetch and never charged. Large arrays are fine.

Questions and answers

How much does it cost to scrape Instahyre?

$0.0008 per job with its full description plus $0.001 per run, so 100 jobs cost about $0.08 and a 50-jobs-a-day feed about $1.25 a month.

Is there an official Instahyre API?

No public one. This Actor reads the JSON that the Instahyre website itself loads for its job search, plus the public job pages, and exposes them as a REST API with schedules, webhooks and only-new-jobs runs.

Does it return the full job description?

Yes, as HTML and plain text, plus the experience range, posting date, job functions, skills and the company profile with headcount, founding year and website.

Why is the posting date old on many jobs?

Instahyre keeps a job open until the employer closes it, so a feed without postedWithinDays includes jobs posted months ago. Use postedWithinDays for recent postings, or only-new mode, which after the first run delivers only jobs that are new on the site.

Does it include salaries or applicant counts?

No. Instahyre does not publish salary ranges or applicant counts on public job pages, and this Actor only reads public data.

Why does a city return nothing?

The site only accepts the location names it lists; the Actor maps the common alternative spellings and names any location it had to ignore in the status message. Use Bangalore, Delhi, Gurgaon, Noida, Mumbai, Hyderabad, Chennai, Pune, Kolkata, Ahmedabad or Work From Home.

Do I need a proxy or login?

No.
