India IPO GMP: pay-per-record data API

India IPO Tracker API – Live GMP, Subscription & SME IPOs is a pay-per-record data API on Apify that returns live IPO GMP, QIB/NII/retail subscription, calendar, listing data as JSON, CSV or Excel. It costs $0.003 per ipo report row ($3.00 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

Run it on Apify   Listing as plain text for agents

What you get

An Indian IPO data feed you can plug into a broker app, fintech dashboard, research workflow or alert service without maintaining scrapers. Each run returns structured JSON for upcoming, open and recently listed mainboard and SME IPOs on BSE and NSE: live grey market premium (GMP), live QIB / NII / Retail subscription, the IPO calendar (open, close, allotment, refund, listing), listing-day gains, GMP vs actual listing price, and optionally the full IPO detail page (price band, lot size, reservation, anchor investors, financials, objects of the issue).

Why use it

  • Two sources joined for you. GMP and subscription come from different public IPO reports. Every record carries the same stable slug (e.g. paras-healthcare-ipo), so you can join reports without fuzzy name matching.
  • Mainboard and SME in one feed, with ISIN, BSE scrip code and NSE symbol on subscription, IPO-list and listing-performance rows for joining to your security master.
  • Cheap to poll. Plain HTTP, no browser: a GMP refresh costs about 15 cents.
  • Never fails on input. Unknown options are ignored with a warning and the run still succeeds, so schedules and webhooks keep working.
  • No contract. Pay per row, cancel by stopping the schedule.

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~india-ipo-tracker/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reports": ["gmp", "subscription"], "category": "all"}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/india-ipo-tracker with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/india-ipo-tracker.py, node/india-ipo-tracker.mjs, n8n/india-ipo-tracker.json.

Input fields

FieldTypeMeaning
reportsarrayWhich IPO datasets to extract. Each produces its own reportType records. Default: live GMP (gmp) plus the IPO event calendar (calendar), about 80 rows, about $0.25 at $0.003 per row. Add subscription for QIB/NII/Retail multiples (every IPO of the current calendar year so far, about 300 rows) and currentIpos for status, price band, lot size and dates (about 300 rows). gmpPerformance compares the last GMP with the actual listing price (about 280 rows per year).
categorystringMainboard IPOs, SME IPOs, or both (all). Applies to every report except the event calendar.
yearintegerCalendar year (YYYY, 2000 to next year) for the year-scoped reports. Leave empty for the current year (recommended). Only gmpPerformance has full history for past years (2025 returns about 380 rows); ipoList, subscription, listingPerformance and currentIpos return only a handful of rows for past years because the sources publish them for the current calendar year. gmp and calendar are always live and ignore this field. Invalid values are ignored with a warning, the run does not fail.
includeIpoDetailsbooleanAlso fetch each IPO's detail page (price band, lot size, timetable, reservation, anchor investors, financials, objects of the issue). Emits one extra ipoDetail record per IPO, charged $0.015 per detail page on top of the rows.
maxItemsintegerStop after this many records (0 = no limit). Each record costs $0.003; each IPO detail page $0.015.

Questions and answers

How much does it cost to get Indian IPO GMP and subscription data?

The default run (live GMP + calendar, about 80 rows) costs about $0.25 at $0.003 per row. A GMP-only poll is about $0.15. Full IPO detail pages cost $0.015 per IPO.

How often is the data updated?

Every run reads the sources live. Schedule it every 30 minutes during IPO bidding hours for a near-real-time feed.

Does it cover SME IPOs?

Yes. Set category to sme, mainboard or all. Every record carries category so you can also filter afterwards.

Can I get past years?

Only for gmpPerformance (GMP vs listing price), which has full history per calendar year through the year field. The other year-scoped reports are published by the sources for the current calendar year only, so past years return just a few rows.

Do I need a proxy or login?

No. The sources answer plain HTTP requests, so runs finish in seconds.

What happens if a source is down?

Reports that cannot be fetched are logged and skipped; the run still succeeds with whatever was collected. Only when every requested report is unreachable and nothing was collected does the run fail with a clear message, so your webhook can alert you.
