ImportYeti US import records (bills of lading) API

ImportYeti Scraper & API is a pay-per-record Apify Actor by Daemon Data that returns US import records from ImportYeti: latest bills of lading per importer or supplier, or a company profile with top suppliers as JSON, CSV or Excel. It costs $0.002 per shipment with the default options ($2.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-09; this build does not run paid example searches.

{
  "companies": [
    "walmart"
  ],
  "output": "shipments",
  "maxResults": 100
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~importyeti-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"companies": ["walmart"], "output": "shipments", "maxResults": 100}'

Python: ApifyClient(token).actor("data_daemon/importyeti-scraper").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/importyeti-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
companiesarrayCompany names or ImportYeti URLs, e.g. Walmart, ikea-supply, https://www.importyeti.com/company/wal-mart. A name is turned into the page address (Ikea Supply becomes /company/ikea-supply); if it is not found, copy the exact URL from importyeti.com.
suppliersarraySupplier names or ImportYeti supplier URLs, e.g. https://www.importyeti.com/supplier/foxconn. Shipments then list the US importers they ship to.
outputstringshipments: one row per recent bill of lading (the page lists the 50 newest). profile: one row per company with totals, top suppliers (or, for supplier pages, top US buyers), HS codes, port lanes and monthly shipments for up to the last 24 months that had shipments.
shippedWithinDaysintegerShipments mode: keep bills of lading dated within the last N days.
maxShipmentsPerCompanyintegerUp to 50 (ImportYeti shows the 50 newest bills of lading per company).
topSuppliersintegerProfile mode: how many suppliers (company pages) or US buyers (supplier pages) to include, up to 50, largest first.
maxResultsintegerStop after this many saved rows (default 100). 0 = no cap.
onlyNewSinceLastRunbooleanShipments: skip bills of lading delivered by earlier runs. Profiles: deliver a company again only after it has a newer shipment. Memory is kept in a key-value store named importyeti-state (skipped rows are not charged).
stateNamestringBy default it follows the output and the company list.
skipIdsarrayBill of lading numbers (shipments) or company/<slug> ids (profiles) you already have. Not saved, not charged.

Price

$0.002 per shipment ($2.00 per 1,000); $0.01 per company profile ($10.00 per 1,000); $0.001 per run. List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.

EventPricePer 1,000Charged when
Shipment$0.002$2.00One bill of lading saved to the dataset: date, supplier and country, weight, quantity, containers, cargo description, route, estimated freight cost. Rows skipped by only-new mode, skipIds or the date filter are never charged.
Company profile$0.01$10.00One company profile saved to the dataset: totals, up to 50 suppliers with volumes and HS codes, HS-code breakdown, port lanes and the 24-month shipment trend.
Actor Start$0.001Charged when the Actor starts running. Number of events charged depends on Actor memory (one event per GB, minimum one event).

Cost example: 50 shipments with default options cost $0.101, including any start fee. This is an illustrative record count; set explicit row and total-charge caps for your run. Apify's free plan includes $5 of usage a month, about 2,500 shipments before start fees; the Actor's own compute is included in the per-record price, and records skipped by filters, de-duplication or only-new mode are not charged.
