Oracle HCM career sites: pay-per-record data API

Oracle Jobs Scraper – Oracle HCM & Recruiting Cloud Career Site is a pay-per-record data API on Apify that returns every requisition on any Oracle Recruiting Cloud career site as JSON, CSV or Excel. It costs $0.002 per job ($2.00 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

Run it on Apify   Listing as plain text for agents

What you get

Get every open job from any Oracle Recruiting Cloud career site as clean JSON. Thousands of large employers (banks, hotel groups, hospitals, universities, manufacturers, governments) run their careers page on Oracle Recruiting Cloud, part of Oracle Fusion Cloud HCM. You can recognise it by URLs like *.oraclecloud.com/hcmUI/CandidateExperience/.... The career site is the employer's own source of truth, with every requisition and the full posting text. This Actor reads the career site's own JSON API and returns every open requisition (the default run stops at 50 jobs per site; set Max jobs per site to 0 for the whole site): title, all locations, country, posted date, job function and family, schedule, and, with details on, the full description, qualifications, responsibilities, skills and the employer's own custom fields (job type, years of experience, visa sponsorship and whatever else they configured).

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~oracle-hcm-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"careerSiteUrls": ["https://eeho.fa.us2.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_45001/requisitions"], "keyword": "engineer", "postedWithinDays": 30, "includeDetails": true, "maxJobsPerSite": 50}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/oracle-hcm-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/oracle-hcm-jobs-scraper.py, node/oracle-hcm-jobs-scraper.mjs, n8n/oracle-hcm-jobs-scraper.json.

Input fields

FieldTypeMeaning
careerSiteUrlsarrayOne or more Oracle Recruiting Cloud (Oracle HCM) career site URLs. They look like https://{tenant}.fa.{region}.oraclecloud.com/hcmUI/CandidateExperience/en/sites/{siteNumber}; any page of the site works, including a single job URL. Example: JPMorgan Chase = https://jpmc.fa.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001. To find a company's site, web-search: site:oraclecloud.com CandidateExperience "". Taleo and Workday sites are not supported.
keywordstringOptional. Searched the way the career site's own search box does, e.g. data, nurse, sales manager. Leave empty to export every open job.
locationstringOptional country, state or city, e.g. India, United Kingdom, London, Bengaluru, Karnataka, India. Countries always work. States and cities are resolved through the site's own location filter; if the site does not list the place, jobs are matched on their location text instead and only matching jobs are delivered and charged. The run log lists the locations a site offers.
postedWithinDaysintegerOnly jobs posted recently. Integer 1-30; Oracle supports two buckets, so 1-7 means the last 7 days and 8-30 the last 30 days. Leave empty for all open jobs.
workplaceTypesarrayOptional: only remote, hybrid or on-site jobs. Works only on career sites that tag workplace type; some tag every job on-site (Oracle's own site does), and then Remote returns 0 jobs.
includeDetailsbooleanOn (default): full description, qualifications, responsibilities, skills and the employer's custom fields. Adds $0.002 per job. Off: list fields only, at half the price.
maxJobsPerSiteintegerStop after this many jobs per career site (default 50, about $0.20 with details at FREE prices). Set 0 to export the whole site; large employers list 2,000-13,000 open jobs.
onlyNewSinceLastRunbooleanDeliver only jobs that an earlier run with the same search (or the same State key) has not already delivered. Skipped jobs are not charged. Made for daily schedules: the Actor remembers delivered job IDs in a key-value store named oracle-hcm-jobs-state in your account. When this is on and Posted within is empty, the last 7 days are searched.
stateNamestringOptional name for this saved search's memory when Only new jobs is on, e.g. jpmc-india. Leave empty to derive it from the career site URLs, keyword, location and workplace types. Use a new key to start over.
skipJobIdsarrayOptional requisition IDs to leave out, e.g. the id values from an earlier run. Skipped jobs are not charged. Large lists are fine.
maxJobsintegerHard cap for the whole run across all sites (0 = no cap).

Questions and answers

How much does it cost to scrape an Oracle career site?

$0.002 per job plus $0.002 per full detail record. A 500-job site with details costs $2.00; the same site without details costs $1.00.

Does Oracle Recruiting Cloud have a public API for job postings?

The documented Oracle HCM REST API needs customer credentials. Public career sites load their jobs from an unauthenticated candidate-experience endpoint (/hcmRestApi/resources/latest/recruitingCEJobRequisitions), which is what this Actor reads, with the same filters the careers page uses.

What is the difference between Oracle HCM, Oracle Fusion and Oracle Recruiting Cloud?

Oracle Fusion Cloud HCM is the suite. Oracle Recruiting Cloud (ORC) is its recruiting module. The public careers page is called Candidate Experience, which is why the URLs contain CandidateExperience.

Does it read Taleo or Workday sites?

No. Taleo is Oracle's older, separate ATS and Workday is a different vendor. This Actor covers Oracle Recruiting Cloud (oraclecloud.com/hcmUI/CandidateExperience) sites only. Other hosts are skipped with a warning, not an error.

Why do I see several sites (CX_1, CX_1001, CX_45001) for one employer?

Tenants keep backup, campus and alumni sites. Use the one in the table above, or the one your browser shows on the employer's careers page. Oracle's own retired CX_1 still answers, but the live site is CX_45001.

Can I filter by city?

Yes. Cities and states are matched against the site's own location filter (for example LONDON, United Kingdom on JPMorgan Chase or Dubai, United Arab Emirates on Marriott). If a site only lists states, as Kotak does, the Actor matches the city against each job's location text instead, and only matching jobs are charged.

Which companies use Oracle Cloud HCM career sites?

Thousands of large employers: banks, hospitals, universities, manufacturers, retailers, hotel groups and governments. Their career pages live under oraclecloud.com/hcmUI/CandidateExperience/.

Do I need a proxy or login?

No.
