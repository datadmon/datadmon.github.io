BSE corporate announcements and filings as JSON API

BSE Corporate Announcements API is a pay-per-record Apify Actor by Daemon Data that returns BSE India corporate filings: announcements with category, subject, summary and PDF link, corporate actions with ex-dates, board meetings, the results calendar and bulk and block deals, with scrip code, symbol and ISIN on equity rows as JSON, CSV or Excel. It costs $0.003 per filing row with the default options ($3.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Checked on 10 Nov 2026

BSE carried 13,616 equity announcements for 2-9 Nov 2026 (1,733 to 3,114 on each trading day of 2-6 Nov) and 26,652 for October; one run returned all 3,114 announcements of 5 Nov in 80 seconds. The same day it listed 2,456 corporate actions with a 2026 ex-date, 1,745 forthcoming result dates and 318 bulk and block deals for 2-10 Nov. A {} run returns the 50 newest announcements in about 3 seconds.

Why teams use it

  • Rows, not pages. BSE shows filings in browser tables, 50 to a page, and the whole market only one day at a time. This Actor walks the pages and returns the same public data as clean JSON with ISO dates in India time, numbers as numbers and stable field names.
  • Symbol and ISIN on the row. BSE's filing tables identify a company by scrip code. Each row here also carries the BSE symbol and, for securities in BSE's list of active equity securities, the ISIN and the BSE group (A, B, X, T, M for SME ...), so the feed joins to prices, holdings or an NSE feed without a mapping table. Of the 3,114 equity announcements of 5 November 2026, all carried a symbol and 3,035 an ISIN.
  • A feed that delivers each filing once. With onlyNew the Actor remembers what it delivered. Schedule it with daysBack: 2: a filing broadcast late at night is still picked up next morning, and nothing is delivered or charged twice.
  • Filter before you pay. symbols, categories and keywords are applied before rows are saved, so a watchlist or a "dividends only" feed costs cents.
  • Parsed corporate actions. "Interim Dividend - Rs. - 24.0000" becomes actionType: "dividend", amountPerShare: 24; "Bonus issue 1:1" becomes ratio: "1:1"; a split carries the old and new face value.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-10; this build does not run paid example searches.

{
  "reports": [
    "announcements"
  ],
  "daysBack": 2,
  "maxItems": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~bse-corporate-announcements/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reports": ["announcements"], "daysBack": 2, "maxItems": 50}'

Python: ApifyClient(token).actor("data_daemon/bse-corporate-announcements").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/bse-corporate-announcements with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
reportsarrayWhich BSE filing feeds to read. Each row carries its reportType. announcements (default): every corporate announcement with category, subcategory, subject, summary text and PDF link (1,700-3,100 on a weekday in results season). corporateActions: dividends, bonus, splits, rights and buybacks by ex-date. boardMeetings: meeting date and purpose. resultsCalendar: forthcoming financial-result dates. deals: bulk and block deals with client, side, quantity and price.
symbolsarrayCompanies to keep: BSE scrip codes (500325), BSE symbols (RELIANCE, TCS, HDFCBANK) or ISINs (INE002A01018), mixed freely. Empty = the whole market. With up to 25 companies the announcements and corporate actions are read per company, so a year of history for a watchlist is a small run.
categoriesarrayKeep rows whose category contains one of these words (case-insensitive). For announcements this matches BSE's category and subcategory, for example Result, Board Meeting, Corp. Action, Dividend, Credit Rating, Press Release, Investor Presentation, Acquisition, Award of Order, Insider Trading, AGM. For corporate actions and board meetings it is the purpose (Dividend, Bonus, Split, Quarterly Results, Preferential Issue). Empty = all.
keywordsarrayKeep rows whose company name, symbol, scrip code, category, subject or summary text contains one of these words (case-insensitive), for example order, preferential, QIP, demerger. Empty = all.
daysBackintegerFor announcements and deals: how many days before today (India time) to read, today included. 0 = today only, 2 (default) = today and the two days before. Ignored when From date is set.
daysAheadintegerFor corporate actions (ex-dates), board meetings and the results calendar: how many days after today to read, soonest first. Default 30. Ignored when To date is set.
fromDatestringFirst day (YYYY-MM-DD, India time) for every selected report. Use with To date for a backfill. BSE serves whole-market announcements one day at a time, 50 per request: a day of 3,114 rows took 80 seconds (checked 10 Nov 2026), so allow about half a minute per 1,000 rows.
toDatestringLast day (YYYY-MM-DD, India time). Empty = today for announcements and deals, today + Days ahead for calendars.
segmentsarrayFor the announcements report. equities (default) covers listed companies, including the BSE SME platform (those rows carry group M or MT) and InvITs/REITs. debt is filings by issuers of listed debt, mf is mutual funds and ETFs; both are large daily lists.
dealTypesarrayFor the deals report: bulk deals and block deals (client, buy or sell, quantity, price). Default: both.
maxItemsintegerStop each report after this many rows (newest first for announcements and deals, soonest first for calendars). 0 = no limit. Each row costs $0.003, so the default 50 rows cost $0.15.
onlyNewbooleanRemember what was delivered and return only rows that are new since the last run with the same state name. Rows already delivered are skipped and not charged again, so a scheduled run with Days back 2 never misses a late filing and never bills one twice.
stateNamestringName of the only-new memory. Use a different name for each independent feed (for example one per watchlist). Letters, digits, dash and underscore.
