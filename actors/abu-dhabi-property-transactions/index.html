Abu Dhabi property transactions (ADREC sold prices) as JSON API

Abu Dhabi Property Transactions API is a pay-per-record Apify Actor by Daemon Data that returns Abu Dhabi property sales from ADREC market data since 2019 with AED price, price/sqm, district, project and bedrooms as JSON, CSV or Excel. It costs $0.001 per sale with the default options ($1.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Checked on 12 Nov 2026

ADREC's table held 127,379 sales from 2 Jan 2019 to 11 Nov 2026 (25,114 in 2025; 27,636 so far in 2026). October 2026: 3,046 sales, 2,934 of them in Abu Dhabi City, 94 in Al Ain and 18 in Al Dhafra; 2,407 off-plan, 628 ready, 11 court-mandated; 2,152 primary and 894 resale. A full-month run returned all 3,046 rows in 22 seconds, matching the source count.

Why teams use it

  • Every row, once. The page's table is paged by a single column, and rows that tie on it change order between requests. On 12 November 2026 a plain read of October 2026 at 1,000 rows per page repeated or lost 71 of 3,046 rows (448 at 300 per page). This Actor reads with a full ordering and checks every window against the source's own count: the same month came back complete, row for row.
  • History in one place. The table goes back to 2 January 2019, so one run returns almost eight years of sales (the 9,990 sales of 2019 came back in 26 seconds).
  • Municipality on every row. The source does not put the municipality on a row; the Actor reads each municipality separately and adds it.
  • A feed that never charges twice. Only-new mode remembers what a feed has delivered.
  • Clean fields. Bedrooms as a number, offPlan as true / false, price per sqm rounded, and the same field names as our Dubai DLD transactions Actor where the meaning is the same, so one pipeline can hold both emirates.

Output fields

The most useful top-level fields with values from a real record; the full list is transactionDate, municipality, district, community, project, assetClass, propertyType, layout, bedrooms, saleType, offPlan, saleSequence, transactionValueAed, soldAreaSqm, plotAreaSqm, soldShare, pricePerSqmAed, source, scrapedAt. Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-12; this build does not run paid example searches.

{
  "daysBack": 7,
  "maxItems": 200
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~abu-dhabi-property-transactions/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"daysBack": 7, "maxItems": 200}'

Python: ApifyClient(token).actor("data_daemon/abu-dhabi-property-transactions").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/abu-dhabi-property-transactions with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
fromDatestringStart of the range, YYYY-MM-DD (DD/MM/YYYY also accepted), matched against each sale's transactionDate. Leave empty to use Days back instead, so a scheduled run never needs a date edit. The table starts on 2 January 2019. An invalid date is ignored with a warning.
toDatestringEnd of the range (included), YYYY-MM-DD. Defaults to today (UTC). ADREC publishes a day's sales on the following day.
daysBackintegerUsed when From date is empty: fetch the last N days up to To date (or today). Default 7. Abu Dhabi registers about 100-250 sales per working day (3,046 in October 2026) and almost none on weekends. For a daily scheduled feed use 7 with Only new sales on: late registrations are caught and nothing is charged twice.
municipalitystringall, abuDhabiCity, alAin or alDhafra. October 2026: Abu Dhabi City 2,934 sales, Al Ain 94, Al Dhafra 18. Every row carries its municipality.
offPlanstringSale type: all, offplan, ready or courtMandated. October 2026: 2,407 off-plan, 628 ready, 11 court-mandated.
saleSequencestringall, primary (first sale by the developer) or secondary (resale). October 2026: 2,152 primary, 894 secondary.
assetClassstringall, residential, commercial, agricultural or other. About 96% of sales are residential.
propertyTypesarrayKeep only these property types, e.g. apartment, villa, townhouse / attached villa, duplex, penthouse, plot for villa, office, retail, farm. Use the values of the propertyType field. Empty = all.
layoutsarrayKeep only these layouts: studio, 1 bed, 2 beds, 3 beds, 4 beds, 5 beds, 5+ beds, 6+ beds. Empty = all.
districtsarrayKeep only these districts, e.g. Al Reem Island, Yas Island, Al Saadiyat Island, Al Hidayriyyat, Khalifa City. Spelling follows ADREC (the district field of any row); case does not matter. A name ADREC does not list is reported in the run's status. Empty = all.
communitiesarrayKeep only these communities (the community field, e.g. RT7, Al Hidayriyyat Island). Empty = all.
projectsarrayKeep only these projects (the project field, e.g. Reem Hills - Phase 1C, River Cove Residences). Exact names, case does not matter. Empty = all.
maxItemsintegerStop after this many sales (0 = all in range). Each sale costs $0.001, so the default 200 = $0.20 and a month of about 3,000 = $3. The whole table since 2019 is about 127,000 sales ($127).
onlyNewbooleanFor scheduled feeds: skip sales an earlier only-new run already delivered, so overlapping date windows are never charged twice. Memory is kept per Feed state name and filter combination in the named key-value store abu-dhabi-sales-only-new and covers the last 120 days of sale dates. Recommended schedule: daily with Days back 7 and this on. Don't run two only-new runs of the same feed at the same time.
stateNamestringName of your only-new feed, e.g. abu-dhabi-sales-daily. Separate names keep separate memories. Ignored unless Only new sales is on.
sortstringnewest or oldest by sale date. Matters only when maxItems cuts the range short.
