ChatGPT Business Hub product feed generator (CSV / JSONL)

ChatGPT Product Feed Generator for Business Hub (CSV / JSONL) is a pay-per-record Apify Actor by Daemon Data that returns the OpenAI product feed for ChatGPT Business Hub (CSV and JSONL) built from a Google Merchant feed, a WooCommerce store or schema.org product pages, with every row checked against the spec as JSON, CSV or Excel. It costs $0.001 per product row with the default options ($1.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

A run converted a 100-product WooCommerce store with 354 variations into a 400-row OpenAI product feed in 30 seconds: 3 rows were rejected for a zero price and 72 were flagged for a missing description. A {} run converts a 24-row sample Google Merchant feed in about 3 seconds: 20 rows written, 4 rejected for the mistakes planted in the sample.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-11; this build does not run paid example searches.

{
  "merchantFeedUrls": [
    "https://datadmon.github.io/data/samples/google-merchant-sample-feed.xml"
  ],
  "sellerName": "Juniper Ridge Outfitters"
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~chatgpt-product-feed-generator/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"merchantFeedUrls": ["https://datadmon.github.io/data/samples/google-merchant-sample-feed.xml"], "sellerName": "Juniper Ridge Outfitters"}'

Python: ApifyClient(token).actor("data_daemon/chatgpt-product-feed-generator").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/chatgpt-product-feed-generator with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
merchantFeedUrlsarrayLinks to product feed files in Google Merchant Center format: XML (RSS or Atom with g: fields), TSV or CSV, plain or gzipped. Most shop platforms and feed plugins can give you this link (WooCommerce feed plugins, BigCommerce, Magento, Wix, Squarespace, Shopify feed apps). This is the most complete source because the file already has brand, GTIN, variants and sale prices. Leave every source empty to convert a sample feed and see the output.
wooCommerceStoreUrlsarrayHome page of a WooCommerce store, for example https://shop.example.com. The Actor reads the store's public product API (/wp-json/wc/store/v1/products): every published product with price, stock, images, categories, ratings and variations. No plugin and no login. If the store has switched that API off, use its feed URL or sitemap instead.
sitemapUrlsarraySitemap or sitemap index of a shop, for example https://shop.example.com/sitemap.xml. Product pages found in it are opened and their schema.org Product markup (JSON-LD) is read. Works on any platform that prints that markup, which most do for Google.
productPageUrlsarrayIndividual product pages to read (schema.org Product / ProductGroup JSON-LD). Use it for a small catalogue or to test a few pages.
productUrlPatternstringRegular expression that tells product pages apart from other pages in a sitemap. Default /(products?|p|item|shop|dp)/.
sellerNamestringYour store's name as customers should see it. OpenAI requires seller_name on every row. When empty, the name is read from the feed title, the WooCommerce site name or the page's site name.
brandFallbackstringOpenAI requires brand on every row. Products that have a brand in the source keep it. For the rest this value is used; when it is empty the seller name is used and the row gets a warning.
sellerUrlstringOptional seller_url: your storefront's home page.
returnPolicyUrlstringOptional return_policy: public page with your return terms.
returnDeadlineDaysintegerOptional. When set, every row gets accepts_returns: true and return_deadline_in_days. Leave 0 to leave returns unspecified.
currencystringThree-letter ISO code, for example USD. Only used when a price has no currency code (a bare 19.99 or $19.99).
urlSuffixstringOptional query string added to every product url, for example utm_source=chatgpt.com&utm_medium=feed. Parameters already on the link are kept.
expandVariantsbooleanOpenAI wants one row per purchasable variant, linked by group_id with the options in variant_dict. Turn off to write one row per product.
includeOutOfStockbooleanOut-of-stock products stay in the feed with availability: out_of_stock (recommended: OpenAI treats each upload as the full catalogue). Turn off to leave them out; they are then not charged.
maxItemsintegerStop after this many product rows (for a test run). 0 = the whole catalogue. A capped file is not a full snapshot, so do not upload it as your live feed.

Questions buyers ask

What is Businesses in ChatGPT (Business Hub)? OpenAI opened it in beta on 10 November 2026. A business claims its profile at chatgpt.com/business-hub, verifies it, and can then edit its details, see how often ChatGPT mentions and links to it, and add a product catalogue. Shopify stores connect an app; other stores upload a product file in OpenAI's format, which is what this Actor produces.

Does this upload the feed to ChatGPT for me?

No. The Actor never signs in to your ChatGPT account, and claiming a profile needs your own verification. You download the file from the run and upload it yourself.

Does a product feed make ChatGPT recommend my products? OpenAI says claiming a profile does not guarantee placement. The feed gives ChatGPT accurate names, prices, stock and links for your products; whether it shows them is OpenAI's decision.

Can it read a Shopify store?

Shopify stores can use OpenAI's Shopify connection, so this Actor does not read Shopify's storefront JSON. If you want a file anyway, pass the Google Shopping feed URL from your Shopify feed app, or your sitemap.

My WooCommerce store returns an error. Why? Some stores switch off the public Store API or sit behind a bot check. Pass the store's Google Merchant feed URL instead (any WooCommerce feed plugin gives you one), or its sitemap, or turn on Apify Proxy in the input.

Is there an API for this?

Yes. Start a run with the Apify API, wait for it to finish and download chatgpt-product-feed.jsonl from the run's key-value store. Python and Node.js clients, n8n, Make and Zapier work the same way, and AI agents can call it through https://mcp.apify.com/?tools=data_daemon/chatgpt-product-feed-generator.
