India Jobs MCP: 10 Indian job boards for agents

India Jobs MCP is an MCP server for AI agents (Claude, Cursor, VS Code and any client that speaks the Model Context Protocol) that searches ten Indian job boards: Naukri, IIMJobs, Hirist, foundit, Instahyre, Shine, Cutshort, Apna, WorkIndia and Unstop. Your agent asks for "product manager jobs in Bangalore posted this week" and gets back one compact list: title, company, city, remote/onsite, experience in years, salary in LPA, skills, posting date and the job link, with the same job on two boards folded into one. A new_jobs_since watch returns only jobs the agent has not seen before, for daily alerts. No fee of its own: each search runs that board's Daemon Data Actor in your Apify account at the board's per-job price (20 Naukri jobs cost about $0.017).

Price and coverage

No fee of its own. Searches run the selected board Actors in your Apify account at each board’s price, including any start fee. Platform usage may apply. Boards: Naukri, IIMJobs, Hirist, foundit, Instahyre, Shine, Cutshort, Apna, WorkIndia and Unstop. Salary is normalized to LPA; cross-board duplicates are folded conservatively. Source salary and description coverage varies.

Connect an AI assistant

Use this Streamable HTTP MCP URL with your Apify token in the Authorization header:

https://data-daemon--india-jobs-mcp.apify.actor/mcp
Authorization: Bearer YOUR_APIFY_TOKEN

Tools: search_jobs, search_all_boards, new_jobs_since, get_results, list_boards. Start with list_boards to read coverage and live board prices. Searches can return pending run IDs; collect them with get_results.
