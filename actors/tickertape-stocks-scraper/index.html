NSE/BSE stocks (Tickertape): pay-per-record data API

Indian Stock Market API – NSE/BSE Fundamentals (Tickertape) is a pay-per-record data API on Apify that returns NSE/BSE index constituents, ratio screener, full stock profiles as JSON, CSV or Excel. It costs $0.02 per stock profile ($20.00 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

Run it on Apify   Listing as plain text for agents

What you get

NSE and BSE fundamentals as an API, without an exchange data licence and without fighting NSE's bot protection. Built on Tickertape's public stock pages. One record per stock gives you the live quote, key ratios, Tickertape's scorecard, 10 years of income statement, balance sheet and cash flow, quarterly results, promoter / pledged / FII / DII / mutual-fund shareholding history, dividends, corporate actions, analyst forecasts, top mutual-fund holders and peers. It also returns index constituents (NIFTY 50, NIFTY NEXT 50, NIFTY 500, NIFTY BANK, NIFTY IT, SENSEX …) with price, market cap, P/E, P/B and dividend yield, and runs a custom ratio stock screener.

Why use it

  • The whole stock page in one record. Statement lines come with readable names (Total Revenue, Net Income, EPS, Free Cash Flow), not just codes.
  • Shareholding as a trend. Six quarters of promoter, pledged, FII, DII, MF, insurance and retail percentages: compare quarters to spot FII exits or rising promoter pledges.
  • Screener plus enrichment. Filter on market cap, P/E, P/B, dividend yield, ROE, ROCE, debt/equity, 1-week to 1-year returns, beta, promoter pledge and FII/DII holding, then pull the full profile for every match in the same run.
  • Never a failed run on a typo. An unknown index name, a stock that does not exist or a screener with no matches finishes successfully with 0 rows and a status message that says why, so schedules and webhooks keep working.
  • Fast. Index and screener rows arrive in seconds; a 50-stock full-profile run finishes in about a minute. Plain HTTP, no browser.
  • From an AI assistant:* add the MCP connector https://mcp.apify.com/?tools=data_daemon/tickertape-stocks-scraper in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~tickertape-stocks-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode": "index", "indexSid": "NIFTY 50"}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/tickertape-stocks-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/tickertape-stocks-scraper.py, node/tickertape-stocks-scraper.mjs, n8n/tickertape-stocks-scraper.json.

Input fields

FieldTypeMeaning
modestringstocks (default): full profiles for the tickers in stocks. index: all constituents of the index in indexSid. screener: rows matching screenerMatch. Set mode explicitly when you use indexSid or screenerMatch; when it is empty, the mode follows whichever of stocks, screenerMatch or indexSid you filled in.
stocksarrayNSE tickers, company names or Tickertape URLs, e.g. RELIANCE, TCS, Infosys, https://www.tickertape.in/stocks/hdfc-bank-HDBK. Each full profile costs $0.02. Leave empty when you use index or screener mode.
indexSidstringFor index mode. Any index Tickertape lists (77 on 2026-10-18), by name or Tickertape id: NIFTY 50, NIFTY NEXT 50, NIFTY 100, NIFTY 200, NIFTY 500, NIFTY BANK, NIFTY IT, NIFTY AUTO, NIFTY FMCG, NIFTY PHARMA, NIFTY METAL, NIFTY REALTY, NIFTY PSU BANK, NIFTY FIN SERVICE, NIFTY MIDCAP 100, NIFTY MIDCAP 150, NIFTY SMALLCAP 100, NIFTY SMALLCAP 250, SENSEX, BSE 500, or ids such as .NSEI, .NN50, .NIFTYIT. Defaults to NIFTY 50. Each row costs $0.002 (or $0.02 with fullProfile).
screenerMatchobjectFor screener mode. Example, large caps with P/E under 20 and ROE over 15%: {"mrktCapf": {"g": 5000}, "apef": {"l": 20}, "roe": {"g": 15}} (g = greater than, l = less than). Field codes: mrktCapf market cap in ₹ crore, apef P/E, pbr P/B, divYield dividend yield %, roe, roce, dbtEqt debt/equity, pr1w 1-week return %, 4wpct 1-month, 26wpct 6-month, 52wpct 1-year return %, beta, promShrPled pledged promoter %, forInstHldng FII %, domInstHldng DII %, sector (e.g. {"sector": "Energy"}). Each row costs $0.002.
screenerSortBystringField code to sort screener results by (default mrktCapf). The sort field is always included in the output rows.
screenerSortDescbooleanSort screener results descending (default) or ascending.
screenerFieldsarrayAdditional Tickertape ratio codes to return per screener row. Every row already carries: subindustry, mrktCapf, lastPrice, apef, pbr, divYield, roe, roce, dbtEqt, pr1w, 4wpct, 26wpct, 52wpct, 52wHigh, 52wLow, beta, promShrPled, forInstHldng, domInstHldng.
fullProfilebooleanFetch the complete profile for every stock ($0.02 each): quote, key ratios, scorecard, 10-year income statement, balance sheet, cash flow, quarterly results, shareholding history, dividends, corporate actions, announcements, analyst forecasts, mutual-fund holders, peers and checklist. Off = lightweight rows ($0.002 each) with price, market cap, P/E, P/B and dividend yield. Defaults to on in stocks mode and off in index / screener mode.
maxItemsintegerStop after this many records (0 = no limit). Useful to cap the cost of a NIFTY 500 or screener run.

Questions and answers

How much does it cost to get Indian stock fundamentals?

$0.02 per full stock profile (10 years of statements, quarterly results, shareholding history, dividends, forecasts, peers) and $0.002 per lightweight index or screener row. All of NIFTY 50 with full profiles costs $1.

Which indices are supported?

Any of the 77 indices Tickertape publishes, by name, Tickertape id or index URL: NIFTY 50, NIFTY NEXT 50, NIFTY 100, NIFTY 200, NIFTY 500, NIFTY BANK, NIFTY IT, NIFTY AUTO, NIFTY FMCG, NIFTY PHARMA, NIFTY METAL, NIFTY REALTY, NIFTY PSU BANK, NIFTY FIN SERVICE, NIFTY MIDCAP 100 / 150, NIFTY SMALLCAP 100 / 250, SENSEX, BSE 500 and the other NSE and BSE sector and strategy indices.

What do index rows contain?

Ticker, company name, sector, last price, 1-day change, market cap (₹ crore), P/E, P/B, dividend yield, ROE, 52-week high and low, and free float. Switch on fullProfile for statements, shareholding and forecasts.

Can I run a screener?

Yes. Pass any Tickertape filter object such as {"mrktCapf": {"g": 5000}, "apef": {"l": 20}}. A filter with no matches finishes successfully with 0 rows and a status message.

Do I need a proxy or login?

No.
