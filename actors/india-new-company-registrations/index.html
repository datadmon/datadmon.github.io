New company registrations in India (MCA) API

India New Company Registrations is a pay-per-record Apify Actor by Daemon Data that returns newly incorporated Indian companies from the MCA register: CIN, type, RoC, state, NIC activity, capital, registered office as JSON, CSV or Excel. It costs $0.003 per company with the default options ($3.00 per 1,000); no login to the source site, no proxy, no browser, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Why teams use it

  • Daily feed shape. The register lists incorporations by date. Read the newest date (recentDates: 1) or the last three with only-new mode, and nothing is charged twice.
  • Filter before paying. Company type, state (both from the CIN) and name keywords are checked before any company page is opened; activity keywords and RoC names are checked on the page. Rows outside your filters are never charged.
  • Business facts only. The row is the company: CIN, type, RoC, state, activity, capital, registered office. No personal data of directors.
  • Cheaper than the alternatives. Store actors for MCA data charge $3-10 per 1,000 and most focus on director lookups; this feed is $3 per 1,000 at the FREE tier and less on paid plans.

Input and how to call it

A verified example input (it returned data on 2026-10-31):

{
  "recentDates": 3,
  "companyTypes": [
    "opc",
    "private"
  ],
  "states": [
    "Karnataka"
  ],
  "includeDetails": true,
  "maxResults": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~india-new-company-registrations/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"recentDates": 3, "companyTypes": ["opc", "private"], "states": ["Karnataka"], "includeDetails": true, "maxResults": 50}'

Python: ApifyClient(token).actor("data_daemon/india-new-company-registrations").call(run_input=...), full file python/india-new-company-registrations.py. Node.js: node/india-new-company-registrations.mjs. n8n: importable workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/india-new-company-registrations with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
recentDatesintegerTake the N newest incorporation dates the register lists (1 = the latest day, usually 300-1,000 companies). Ignored when dates or fromDate/toDate are set. For a daily schedule use 2 or 3 with only-new mode, so late additions to earlier days are picked up once.
datesarraySpecific incorporation dates as YYYY-MM-DD, e.g. 2026-10-28. Each date is read in full (all pages).
fromDatestringStart of a date range (YYYY-MM-DD, inclusive). Every listed incorporation date from here to toDate (or the newest) is read.
toDatestringEnd of the date range (YYYY-MM-DD, inclusive).
companyTypesarrayOnly these types (read from the CIN before any page is opened; filtered-out companies are not charged). Empty = all.
statesarrayOnly companies whose state or RoC contains one of these words, e.g. Maharashtra, Karnataka, Delhi, KA, RoC-Bangalore. State names and codes are matched against the state code in the CIN before any company page is opened (fast); RoC names and LLPs are checked on the company page. Rows outside the filter are never charged.
activityKeywordsarrayOnly companies whose NIC activity description or 5-digit NIC code contains one of these, e.g. software, real estate, 62011, retail trade. Checked on the company page.
nameKeywordsarrayOnly companies whose name contains one of these words, e.g. foundation, technologies, hospitality. Checked before any page is opened.
includeDetailsbooleanRead the company page for status, RoC, state, category, class, activity, capital, registered office and the number of directors. Off = listing fields only (name, CIN and what the CIN encodes: type, NIC code, state code, year), which is faster. Same price either way.
maxResultsintegerStop after this many saved companies (default 50, about $0.15). 0 = no cap (the run's maximum cost still applies).
onlyNewSinceLastRunbooleanFor schedules: remember delivered CINs (in a named key-value store in your account) and save only companies that earlier runs with the same filters did not deliver. Skipped companies are not charged.
stateNamestringName of the only-new memory. Empty = derived from the filters (dates do not change it). Give two schedules the same name to share one memory.
skipIdsarrayCINs (or LLPINs) you already have. They are neither saved nor charged.
