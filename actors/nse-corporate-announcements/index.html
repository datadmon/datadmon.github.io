NSE corporate announcements and filings as JSON API

NSE Corporate Announcements API is a pay-per-record Apify Actor by Daemon Data that returns NSE India corporate filings: announcements with category, summary and PDF link, corporate actions with ex-dates, board meetings, bulk and block deals, credit ratings, shareholding patterns and IPO offer documents as JSON, CSV or Excel. It costs $0.003 per filing row with the default options ($3.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

NSE carried 6,933 equity announcements for 2-9 Nov 2026 (904 to 1,530 on each of the five trading days 2-6 Nov, 234 on Monday 9 Nov) and 14,045 for October; one run returned the whole week in 6 seconds. The same day it listed 2,027 corporate actions with a 2026 ex-date, 661 bulk and block deals for the week, and 2,648 offer documents. A {} run returns the 50 newest announcements in about 4 seconds.

Why teams use it

  • Rows, not pages. NSE shows filings in browser tables and offers no free developer API for them. This Actor returns the same public data as clean JSON with ISO dates in India time, numbers as numbers and stable field names.
  • A feed that delivers each filing once. With onlyNew the Actor remembers what it delivered. Schedule it with daysBack: 2: a filing broadcast late at night is still picked up next morning, and nothing is delivered or charged twice.
  • Filter before you pay. symbols, categories and keywords are applied before rows are saved, so a watchlist or a "dividends only" feed costs cents.
  • One call for the whole filing desk. Announcements, ex-dates, board meetings, deals, ratings, shareholding and offer documents share one input and one output format; no separate scraper per NSE page.
  • Parsed corporate actions. "Interim Dividend - Rs 2.50 Per Share" becomes actionType: "dividend", amountPerShare: 2.5; "Bonus 1:1" becomes ratio: "1:1"; a split carries the old and new face value.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-13; this build does not run paid example searches.

{
  "reports": [
    "announcements"
  ],
  "daysBack": 2,
  "maxItems": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~nse-corporate-announcements/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reports": ["announcements"], "daysBack": 2, "maxItems": 50}'

Python: ApifyClient(token).actor("data_daemon/nse-corporate-announcements").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/nse-corporate-announcements with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
reportsarrayWhich NSE filing feeds to read. Each row carries its reportType. announcements (default): every corporate announcement with category, summary text and PDF link (900-1,500 on a weekday). corporateActions: dividends, bonus, splits, rights and buybacks by ex-date. boardMeetings: meeting date and purpose. eventCalendar: results and dividend dates. deals: bulk, block and short-selling disclosures. creditRatings: rating actions by CRISIL, CARE, ICRA and others. shareholdingPatterns: promoter and public holding per filing. offerDocuments: draft, red herring and final prospectuses (the IPO pipeline).
symbolsarrayNSE symbols to keep, for example RELIANCE, TCS, HDFCBANK. Empty = the whole market. With up to 25 symbols the announcements are read per company, so a year of history for a watchlist is a small run.
categoriesarrayKeep rows whose category contains one of these words (case-insensitive). For announcements this is NSE's subject, for example Dividend, Outcome of Board Meeting, Press Release, Investor Presentation, orders, Acquisition, Credit Rating, Resignation, Bonus, Buyback. For corporate actions, board meetings and the event calendar it is the purpose (Dividend, Bonus, Financial Results, Fund Raising). Empty = all.
keywordsarrayKeep rows whose company name, category or summary text contains one of these words (case-insensitive), for example order, preferential, QIP, demerger. Empty = all.
daysBackintegerFor announcements, deals, credit ratings and shareholding patterns: how many days before today (India time) to read, today included. 0 = today only, 2 (default) = today and the two days before. Ignored when From date is set.
daysAheadintegerFor corporate actions (ex-dates), board meetings and the event calendar: how many days after today to read, soonest first. Default 30. Ignored when To date is set.
fromDatestringFirst day (YYYY-MM-DD, India time) for every selected report. Use with To date for a backfill; a month of whole-market announcements is about 12,000-20,000 rows.
toDatestringLast day (YYYY-MM-DD, India time). Empty = today for filings, today + Days ahead for calendars.
segmentsarrayNSE segments. equities (default) is the main board. sme is NSE Emerge (announcements, corporate actions, board meetings, shareholding, offer documents). debt, mf (mutual funds and ETFs) and invitsreits apply to announcements only.
dealTypesarrayFor the deals report: bulk deals (client, buy or sell, quantity, price), block deals, and daily short-selling quantities. Default: all three.
maxItemsintegerStop each report after this many rows (newest first for filings, soonest first for calendars). 0 = no limit. Each row costs $0.003, so the default 50 rows cost $0.15.
onlyNewbooleanRemember what was delivered and return only rows that are new since the last run with the same state name. Rows already delivered are skipped and not charged again, so a scheduled run with Days back 2 never misses a late filing and never bills one twice. An offer document whose stage changes (draft to red herring to final) is delivered again with changeType: "updated".
stateNamestringName of the only-new memory. Use a different name for each independent feed (for example one per watchlist). Letters, digits, dash and underscore.

$0.003 per filing row ($3.00 per 1,000). List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.
