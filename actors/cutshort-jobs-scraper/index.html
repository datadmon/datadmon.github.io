Cutshort startup & tech jobs as JSON API

Cutshort Jobs Scraper is a pay-per-record Apify Actor by Daemon Data that returns Cutshort (cutshort.io) India startup and tech jobs with salary range, experience, skills, remote policy, company profile and full description as JSON, CSV or Excel. It costs $0.0008 per job with the default options ($0.80 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-06; this build does not run paid example searches.

{
  "categories": [
    "Python"
  ],
  "locations": [
    "Bengaluru"
  ],
  "maxResults": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~cutshort-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categories": ["Python"], "locations": ["Bengaluru"], "maxResults": 50}'

Python: ApifyClient(token).actor("data_daemon/cutshort-jobs-scraper").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/cutshort-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
categoriesarrayCutshort job pages to read, newest first: a skill or role (Python, React.js, DevOps, Data Science, Sales, Product Management), a page name (python-jobs, remote-python-jobs, python-jobs-in-mumbai) or a page URL. Python jobs in Mumbai reads the city page. Empty = the whole board (startup-jobs, about 45,000 live jobs).
locationsarrayCity names, e.g. Bengaluru (or Bangalore), Mumbai, Delhi, Hyderabad, Pune, Chennai, Noida, Gurgaon, Kochi. For the 14 cities Cutshort has pages for, the city page is read directly; every job is also checked against its own location list. Delhi includes the NCR (Gurgaon, Noida, Ghaziabad, Faridabad). Empty = all of India and remote.
keywordsarrayWords matched against the job title and skills, e.g. senior, django, lead, intern. Empty = all jobs. Jobs without a match are not charged.
remotestringremote keeps jobs marked remote-only or remote-okay; onsite keeps office-only jobs. With no categories, remote reads Cutshort's remote-jobs page.
roleTypestringFull-time jobs, internships or both.
minExperienceintegerKeep jobs whose experience range reaches this many years (e.g. 3 keeps 2 - 5 years, drops 0 - 2 years).
maxExperienceintegerKeep jobs whose experience range starts at or below this many years (e.g. 2 keeps 0 - 2 and 1 - 4, drops 5 - 8).
minSalaryintegerKeep jobs whose shown annual salary range reaches this amount, e.g. 1500000 for 15 LPA. Jobs that hide their salary (Best in industry) or show a monthly figure are left out when this is set.
postedWithinDaysintegerKeep jobs posted in the last N days (datePosted). Pages are newest first, so reading stops once a page is older than the window.
includeDescriptionbooleanFull job description as text (no extra request; it comes with the listing).
includeCompanybooleanCompany type, size, stage, founding year, website, LinkedIn page, logo and description.
maxResultsintegerStop after this many saved jobs (default 50, about $0.04). 0 = no cap: each Cutshort page serves its newest few hundred to few thousand jobs (about 2,400 on the whole-board page, Oct 2026).
onlyNewSinceLastRunbooleanRemember delivered job ids in a key-value store named cutshort-jobs-state and skip them next time (not charged).
stateNamestringName of the only-new memory. By default it follows categories, locations, keywords and the remote setting.
skipIdsarrayCutshort job ids you already have (the 24-character id). Neither saved nor charged.

$0.0008 per job ($0.80 per 1,000); $0.001 per run. List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.
