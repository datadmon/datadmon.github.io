Magicbricks property listings as JSON API

Magicbricks Scraper is a pay-per-record Apify Actor by Daemon Data that returns Magicbricks India property listings: price, price per sq ft, carpet area, BHK, furnishing, locality, project, coordinates as JSON, CSV or Excel. It costs $0.001 per listing with the default options ($1.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

A verified example input (it returned data on 2026-11-01):

{
  "cities": [
    "Pune"
  ],
  "transactionType": "rent",
  "minBedrooms": 2,
  "maxResults": 40
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~magicbricks-property-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cities": ["Pune"], "transactionType": "rent", "minBedrooms": 2, "maxResults": 40}'

Python: ApifyClient(token).actor("data_daemon/magicbricks-property-scraper").call(run_input=...), full file python/magicbricks-property-scraper.py. Node.js: node/magicbricks-property-scraper.mjs. n8n: importable workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/magicbricks-property-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
citiesarrayCity names as Magicbricks spells them, e.g. Mumbai, Pune, Bangalore (Bengaluru works too), Hyderabad, New Delhi, Gurgaon, Noida, Chennai, Kolkata, Ahmedabad. Each city is its own search; an unknown name is reported, not replaced.
transactionTypestringsale or rent (monthly rent in priceInr).
propertyTypesarrayapartment, builder floor, penthouse, studio, house, villa. Empty = all residential types in one search; with types chosen, each type is its own search (more listings per city).
minPriceintegerSale price or monthly rent; applied by Magicbricks' own budget filter.
maxPriceintegerSale price or monthly rent; applied by Magicbricks' own budget filter.
minBedroomsintegerKeep listings with at least this many bedrooms.
postedWithinDaysintegerKeep listings posted in the last N days (postedAt). 1 is applied by Magicbricks itself (fast); longer windows are checked on each listing.
maxResultsPerSearchintegerCap per city (and property type). 0 = no cap; Magicbricks lists at most 1,500 listings per search.
maxResultsintegerStop after this many saved listings (default 50, about $0.05). 0 = no cap.
onlyNewSinceLastRunbooleanRemember delivered listing ids in a key-value store named magicbricks-state and skip them next time (not charged).
stateNamestringBy default it follows cities, sale/rent and property types.
skipIdsarrayMagicbricks listing ids you already have. Not saved, not charged.

Price

$0.001 per listing ($1.00 per 1,000); $0.001 per run. List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.

EventPricePer 1,000Charged when
Listing$0.001$1.00One property listing saved to the dataset: price, price per sq ft, areas, rooms, locality, project, developer, posting date, coordinates. Listings skipped by only-new mode, skipIds or the filters are never charged.
Actor Start$0.001Charged when the Actor starts running. Number of events charged depends on Actor memory (one event per GB, minimum one event).

Worked example: the input above, capped at 50 listings, costs at most $0.051. Apify's free plan includes $5 of usage a month, about 5,000 listings; the Actor's own compute is included in the per-record price, and records skipped by filters, de-duplication or only-new mode are not charged.
