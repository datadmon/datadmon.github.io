India company data API: MCA CIN lookup, directors and email

India Company Data API (MCA) is a pay-per-record Apify Actor by Daemon Data that returns Indian company records from the MCA register by CIN or name: status, incorporation date, capital, registered office, company email, compliance flags and the board of directors with DIN as JSON, CSV or Excel. It costs $0.003 per company with the default options ($3.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

A run looked up 204 Indian companies in 8 minutes with no failed lookup: 80% carried a company email, 86% a current board (3.6 directors on average), 98% a register status. A second run over a four-company watchlist returned nothing and charged nothing, because no record had changed.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-11; this build does not run paid example searches.

{
  "cins": [
    "L17110MH1973PLC019786",
    "L85110KA1981PLC013115"
  ],
  "companyNames": [
    "Tata Consultancy Services Limited"
  ]
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~india-company-data/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cins": ["L17110MH1973PLC019786", "L85110KA1981PLC013115"], "companyNames": ["Tata Consultancy Services Limited"]}'

Python: ApifyClient(token).actor("data_daemon/india-company-data").call(run_input=...). Python, Node.js and n8n calling instructions. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/india-company-data with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

Each row says how it matched: exact, name (same name without Private / Limited) or partial (starts with your text; check it).

Public-record governance data only: no phone numbers, no personal email. One extra page per company at no extra charge.
includeRelatedCompaniesbooleanAdds relatedCompanies: other companies with at least one common director (name, status, state, number of common directors). Useful for due diligence; makes rows of large groups long.
onlyChangedbooleanFor scheduled runs over the same list. The first run returns every company; later runs return (and charge) only companies whose status, capital, address, email, filing dates, compliance flags or board changed, with changeType and changedFields. Unchanged companies cost nothing.
stateNamestringName of the memory used by watchlist mode. Use a different name for each separate list.
maxItemsintegerStop after this many companies (0 = the whole list).

Questions buyers ask

Where does the data come from? From the Ministry of Corporate Affairs (MCA) company register as shown on the public company pages of InstaFinancials, a company-information site that compiles MCA filings. sourceUpdatedAt shows how recent each record is. It is a copy of the register, not the MCA portal itself: for a legally binding extract use MCA's own certified copies.

Is there an API for MCA company master data?

This Actor works as one: send a list of CINs or names, get the master data and board back as JSON. It does not call an MCA API; it reads a public copy of the register (see above). For certified extracts use MCA's own services.

Does it return directors' phone numbers or personal emails? No. Directors are returned with name, DIN, designation and appointment date, which are public-record governance data. The only contact fields are the company's own email and website.

Why should I keep the proxy on?

The source serves a limited number of pages per IP address. The Actor spreads a list over many addresses through Apify Proxy (datacenter addresses are enough, and they are included in the price). With the proxy off, a run reads only a handful of companies and then stops with a message.

How fresh is a record? sourceUpdatedAt is the date the source last refreshed that company. Large and active companies are refreshed within days or weeks; dormant ones less often.

Can I look up an LLP or a director by DIN?

Not yet. Companies with a CIN only.

Is there an API? Yes. Start a run with the Apify API or the Python / Node.js clients and read the dataset; n8n, Make and Zapier work the same way. AI agents can call it through https://mcp.apify.com/?tools=data_daemon/india-company-data.

Is it legal to use this data?

Company master data and the names of directors are public records under the Companies Act. The Actor reads public pages without logging in and returns no personal contact details. Use the data in line with the laws that apply to you, including India's DPDP Act when you process information about individuals.
