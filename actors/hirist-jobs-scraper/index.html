Hirist tech job listings as JSON API

Hirist.tech Jobs Scraper is a pay-per-record Apify Actor by Daemon Data that returns India IT and tech jobs with full descriptions, skills, salary when disclosed as JSON, CSV or Excel. It costs $0.002 per job ($2.00 per 1,000); no login to the source site, no proxy, no browser, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

A verified example input (it returned data on 2026-10-21):

{
  "queries": [
    "python developer"
  ],
  "locations": [
    "Bangalore"
  ],
  "postedWithinDays": 7,
  "includeDescription": true,
  "maxJobsPerQuery": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~hirist-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["python developer"], "locations": ["Bangalore"], "postedWithinDays": 7, "includeDescription": true, "maxJobsPerQuery": 50}'

Python: ApifyClient(token).actor("data_daemon/hirist-jobs-scraper").call(run_input=...), full file python/hirist-jobs-scraper.py. Node.js: node/hirist-jobs-scraper.mjs. n8n: importable workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/hirist-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
queriesarrayOne Hirist.tech search per keyword, e.g. python developer, data engineer, devops, react native, sap abap. Use role or skill words; put cities in locations. Several specific keywords beat one broad one. A job found by two keywords is saved and charged once.
locationsarrayOptional. Cities as Hirist lists them: Bangalore, Hyderabad, Pune, Chennai, Gurgaon, Noida, Mumbai, Remote, Anywhere in India. Case-insensitive substring match on the job's listed locations; a single known city is also applied server-side for speed. Leave empty for all of India.
minExperienceintegerOnly jobs whose experience range reaches at least this many years. Integer 0-40.
maxExperienceintegerOnly jobs whose experience range starts at or below this many years. Integer 0-40.
postedWithinDaysintegerOnly jobs posted in the last N days. Integer 1-365, e.g. 1 with a daily schedule or 7 for a weekly report. Leave empty for all open jobs.
includeDescriptionbooleanOn (default): full, untruncated description as HTML and plain text, plus the company profile. Adds $0.002 per job. Off: listing fields only, at half the price, which is enough for counting jobs or sizing a market.
maxJobsPerQueryintegerStop a keyword after this many new jobs (default 40). Cost: $0.002 per job plus $0.002 per full description, so 40 jobs with descriptions = $0.16. Raise it for full exports: data engineer alone has about 3,400 open jobs.
maxJobsintegerHard cap on saved jobs for the whole run across all keywords (0 = no cap).
onlyNewSinceLastRunbooleanOn: deliver only jobs that an earlier run with the same stateName has not already delivered, and skip the rest without charging. If postedWithinDays is empty it is set to 3 so each run stays small. Off (default): return every matching job.
stateNamestringOptional name for this search's memory when onlyNewSinceLastRun is on, e.g. python-bangalore-daily. Leave empty to derive it from the keywords, locations and experience filters. Use a new key to start over.
skipJobIdsarrayJob IDs you already have (the id field from earlier runs). They are skipped before any detail fetch and never charged. Large lists are fine.
sitestringKeep hirist (default) for IT and tech jobs. Set iimjobs only for management, finance and MBA jobs from IIMJobs.com; the output format is the same, and the dedicated IIMJobs Jobs Scraper documents it.

Questions buyers ask

How much does it cost to scrape Hirist jobs?

$0.002 per job plus $0.002 per full description, so 100 jobs with descriptions cost $0.40 and a 34-jobs-a-day feed about $4 a month.

Is there a Hirist API?

Not a public one. This Actor reads the JSON the hirist.tech site itself loads and exposes it as a REST API with schedules, webhooks and only-new-jobs runs.

Is Hirist.tech real or fake?

Hirist.tech is a legitimate Indian tech job board owned by Info Edge, the Naukri group. Every row links to the original posting, so you can verify it.

Can I filter by city and experience?

Yes: locations, minExperience, maxExperience and postedWithinDays. A single city is passed to Hirist's own search; several cities are matched on our side.

Does it return the full job description?

Yes, as HTML and plain text, untruncated, plus skills, applicant and view counts, salary in LPA when shown and the AmbitionBox company profile when one exists.

Why is recruiter.name null?

Hirist shows recruiter names only to logged-in users. The Actor keeps the recruiter's designation and does not work around the site's choice. Company name, domain and profile are always included.

Hirist vs Naukri?

Hirist is tech-only and every posting carries skill tags and an experience band, which makes it cleaner for skills analytics. Naukri is broader and noisier.

Can I get Hirist and IIMJobs jobs together?

Yes. IIMJobs Jobs Scraper uses the same output schema and the same onlyNewSinceLastRun mode, so one pipeline handles both boards.
