IIMJobs jobs: pay-per-record data API

IIMJobs Jobs Scraper – MBA, Finance & Management Jobs India is a pay-per-record data API on Apify that returns India MBA, finance, consulting and management jobs with full descriptions as JSON, CSV or Excel. It costs $0.002 per job ($2.00 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

What you get

Turn IIMJobs.com into a clean, scheduled job feed. IIMJobs is India's job board for MBA, finance, consulting, CA/CFA, sales, marketing, HR and senior management roles, the mid-to-senior hiring that general boards bury under fresher listings. This Actor searches IIMJobs by keyword, city, experience band and posting date and returns one JSON row per job with the full job description (HTML + plain text), salary in LPA when the recruiter discloses it, mandatory vs optional skills, applicant and view counts, and the employer's AmbitionBox profile (rating, review count, industry, size, HQ) when it has one.

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~iimjobs-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["product manager"], "locations": ["Bangalore", "Mumbai"], "postedWithinDays": 7, "includeDescription": true, "maxJobsPerQuery": 50}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/iimjobs-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/iimjobs-jobs-scraper.py, node/iimjobs-jobs-scraper.mjs, n8n/iimjobs-jobs-scraper.json.

Input fields

FieldTypeMeaning
queriesarrayOne IIMJobs search per keyword, e.g. product manager, chartered accountant, investment banking, CFO, brand manager. Use role or skill words; put cities in locations. Several specific keywords beat one broad one. A job found by two keywords is saved and charged once.
locationsarrayOptional. Cities as IIMJobs lists them: Mumbai, Bangalore, Delhi NCR, Gurgaon, Pune, Hyderabad, Chennai, Remote, Anywhere in India. Case-insensitive substring match on the job's listed locations; a single known city is also applied server-side for speed. Leave empty for all of India.
minExperienceintegerOnly jobs whose experience range reaches at least this many years. Integer 0-40.
maxExperienceintegerOnly jobs whose experience range starts at or below this many years. Integer 0-40.
postedWithinDaysintegerOnly jobs posted in the last N days. Integer 1-365, e.g. 1 with a daily schedule or 7 for a weekly report. Leave empty for all open jobs.
includeDescriptionbooleanOn (default): full description as HTML and plain text, plus the company profile. Adds $0.002 per job. Off: listing fields only, at half the price, which is enough for counting jobs or sizing a market.
maxJobsPerQueryintegerStop a keyword after this many new jobs (default 40). Cost: $0.002 per job plus $0.002 per full description, so 40 jobs with descriptions = $0.16. Raise it for full exports: product manager alone has about 4,000 open jobs.
maxJobsintegerHard cap on saved jobs for the whole run across all keywords (0 = no cap).
onlyNewSinceLastRunbooleanOn: deliver only jobs that an earlier run with the same stateName has not already delivered, and skip the rest without charging. If postedWithinDays is empty it is set to 3 so each run stays small. Off (default): return every matching job.
stateNamestringOptional name for this search's memory when onlyNewSinceLastRun is on, e.g. pm-bangalore-daily. Leave empty to derive it from the keywords, locations and experience filters. Use a new key to start over.
skipJobIdsarrayJob IDs you already have (the id field from earlier runs). They are skipped before any detail fetch and never charged. Large lists are fine.
sitestringKeep iimjobs (default) for management, finance, consulting and MBA jobs. Set hirist only for IT and tech jobs from Hirist.tech; the output format is the same, and the dedicated Hirist Jobs Scraper documents it.

Questions and answers

How much does it cost to scrape IIMJobs?

$0.002 per job plus $0.002 per full description, so 100 jobs with descriptions cost $0.40 and a 50-jobs-a-day feed about $6 a month.

Is there an official IIMJobs API?

No public one. This Actor reads the JSON that the iimjobs.com website itself loads and exposes it as a REST API with schedules, webhooks and only-new-jobs runs.

Which roles does IIMJobs cover?

Management, consulting, finance, CA/CFA, sales, marketing, HR and MBA-track roles at Indian and global companies, mostly 2 to 25 years of experience.

Does it return the full job description?

Yes, as HTML and plain text, plus skills, applicant and view counts, salary in LPA when disclosed and the AmbitionBox company profile when one exists.

Why is recruiter.name null?

IIMJobs shows recruiter names only to logged-in users. The Actor keeps the recruiter's designation and does not work around the site's choice. Company name, domain and profile are always included.

IIMJobs vs Naukri: which should I scrape?

IIMJobs is curated mid-to-senior management, finance and consulting hiring. Naukri is all levels. For CXO, VP, CA/CFA and MBA roles, IIMJobs has far less noise.

Can I get IIMJobs and Hirist jobs together?

Yes. Hirist.tech Jobs Scraper uses the same output schema and the same onlyNewSinceLastRun mode, so one pipeline handles both boards.

Do I need a proxy or login?

No.
