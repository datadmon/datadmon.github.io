Python Code Runner – pandas, DuckDB & SQL on Apify Datasets data API

Python Code Runner is a pay-per-record Apify Actor by Daemon Data that returns Run your own Python or DuckDB SQL on rows from an Apify Dataset or a JSON array in one API call. pandas, DuckDB, pyarrow and openpyxl preinstalled, extra pip packages on request. Rows back in the Dataset; errors come back as data. About $3 per 1,000 runs. as JSON, CSV or Excel. It costs $0.002 per code run with the default options ($2.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Why teams use it

  • Post-process another Actor's results without downloading them: deduplicate, filter, join, pivot, compute totals, then read the result from this run's Dataset.
  • SQL on an Apify Dataset. SELECT company, count(*) FROM rows GROUP BY company works on any Dataset; no database to set up.
  • A Python step for n8n, Make and Zapier with pandas and the standard library available, called over HTTP.
  • A calculator for AI agents. An agent sends code and rows and gets rows back, with the traceback as data when the code is wrong, so it can correct itself.
  • Scheduled scripts. Save code and settings as a Task and put it on a schedule; API keys go in encrypted environment variables.

Questions buyers ask

Can I run pandas in n8n Cloud?

n8n Cloud's Code node does not allow importing pandas. Call this Actor from an HTTP Request node with the body above; pandas, numpy and DuckDB are available and the response holds the rows.

Can I run SQL on an Apify Dataset?

Yes. Set datasetId and sql; the Dataset's items are the table rows. DuckDB's SQL dialect covers joins, window functions, unnest, JSON functions and regular expressions.

Which Python version and packages?

Python 3.12 with pandas, numpy, duckdb, pyarrow, openpyxl, requests, httpx, beautifulsoup4, lxml and python-dateutil. Anything else from PyPI through packages.

Can my code call the internet?

Yes: requests and httpx are installed. Calls go out from Apify's servers without a proxy.

Limits

50,000 inline rows, 200,000 Dataset rows in, 200,000 rows out (8 MB per row), 20 saved files of at most 50 MB each and 100 MB together, 900 seconds of code time. A DataFrame's named index (for example the keys of a groupby) becomes columns; an unnamed index is dropped.
