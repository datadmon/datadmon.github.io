Foundit jobs: pay-per-record data API

Foundit Jobs Scraper is a pay-per-record data API on Apify that returns foundit.in jobs by keyword, city, experience and freshness, full descriptions included as JSON, CSV or Excel. It costs $0.0008 per job ($0.80 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

Run it on Apify   Listing as plain text for agents

Live check

Live check, 18 Oct 2026: data analyst matched 1,192 open foundit listings (354 in Bangalore, 183 in Delhi NCR, 174 in Hyderabad); 83 of them were posted in the last 7 days. The default run (50 newest data analyst jobs with descriptions) finished in 30 seconds on the Apify platform and cost $0.04 plus the $0.001 start fee.

What you get

Turn foundit.in (formerly Monster India) into a clean, scheduled job feed. foundit is one of India's largest job boards, about 223,000 open listings across IT, sales, finance, healthcare, engineering and BPO roles, from freshers to senior management, with 2,900 new postings a day (counted 18 Oct 2026). This Actor searches foundit by keyword, city, experience band, salary, job type and posting date and returns one JSON row per job with the full job description (HTML + plain text), salary band in INR and LPA when the recruiter discloses it, experience range, skills, industries, functions, applicant and view counts, company profile with coordinates, the foundit job URL and the direct apply URL (the employer's own career site for syndicated jobs).

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~foundit-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["data analyst"], "locations": ["Bangalore"], "postedWithinDays": 7, "includeDescription": true, "maxJobsPerQuery": 50}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/foundit-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/foundit-jobs-scraper.py, node/foundit-jobs-scraper.mjs, n8n/foundit-jobs-scraper.json.

Input fields

FieldTypeMeaning
queriesarrayOne foundit.in search per keyword, e.g. data analyst, java developer, sales manager, chartered accountant, nurse. Use role or skill words; put cities in locations. A job found by two keywords is saved and charged once. Leave the list with one item for a quick first run.
locationsarrayOptional. Cities as foundit lists them: Bangalore, Mumbai, Delhi (covers Delhi NCR: Gurugram, Noida), Hyderabad, Chennai, Pune, Kolkata, Ahmedabad, Remote. Several cities = any of them. Applied by the site, then checked on each job. Leave empty for all of India.
minExperienceintegerOnly jobs whose experience range reaches at least this many years (0-30). From 1 upwards this also excludes jobs that do not state an experience range; 0 keeps them.
maxExperienceintegerOnly jobs whose experience range starts at or below this many years (0-30). 0 or 1 is a good fresher filter.
postedWithinDaysintegerOnly jobs posted or refreshed in the last N days (1-365), e.g. 1 with a daily schedule or 7 for a weekly report. Applied by the site and checked again on each job. Leave empty for all open jobs.
jobTypesarrayOptional. Any of Permanent Job, Contract Job, Work From Home, Internship, Temporary. Several values = any of them. Leave empty for all types.
minSalaryLpaintegerOnly jobs whose disclosed annual salary range reaches at least this many lakh INR, e.g. 10 = 10 LPA = 1,000,000 INR. Most foundit jobs do not disclose pay and are excluded when this is set.
maxSalaryLpaintegerOnly jobs whose disclosed annual salary range starts at or below this many lakh INR. Jobs without a disclosed salary are excluded when this is set.
includeDescriptionbooleanOn (default): one extra request per job adds the full description (HTML and plain text), the company profile, skills with the site's own tags, view count and exact city/state/coordinates. The price per job is the same either way. Off: listing fields only, about twice as fast, enough for counting jobs or sizing a market.
sortstringnewest (default): newest postings first, best for feeds and schedules. relevance: the site's own ranking, best when you only take the first few dozen jobs of a broad keyword.
maxJobsPerQueryintegerStop a keyword after this many new jobs (default 50). Cost: $0.0008 per job with its description, so 50 jobs = $0.04. Raise it for full exports: data analyst alone has about 1,200 open jobs and the site serves 100 per page.
maxJobsintegerHard cap on saved jobs for the whole run across all keywords (0 = no cap).
onlyNewSinceLastRunbooleanOn: deliver only jobs that an earlier run with the same stateName has not already delivered, and skip the rest without charging. If postedWithinDays is empty it is set to 3 so each run stays small. Off (default): return every matching job.
stateNamestringOptional name for this search's memory when onlyNewSinceLastRun is on, e.g. analyst-bangalore-daily. Leave empty to derive it from the keywords, cities and filters. Use a new key to start over.
skipJobIdsarrayArray of job IDs you already have (the id field from earlier runs), e.g. ["69495391", "69497219"]. They are skipped before any detail fetch and never charged. Large arrays are fine.

Questions and answers

How much does it cost to scrape foundit?

$0.0008 per job with its full description plus $0.001 per run, so 100 jobs cost about $0.08 and a 50-jobs-a-day feed about $1.25 a month.

Is there an official foundit API?

No public one. This Actor reads the JSON that the foundit.in website itself loads and exposes it as a REST API with schedules, webhooks and only-new-jobs runs.

Does it return the full job description?

Yes, as HTML and plain text, plus skills, industries, functions, applicant and view counts, salary band when disclosed, the company profile and the direct apply URL.

Why are so many salaries and experience ranges null?

Most postings on foundit are syndicated from employers' career sites without a salary or stated experience band. When the recruiter hides a salary the site does too, and the Actor keeps it hidden (salaryHidden: true). Filter on salaryHidden: false and non-null salaryMinLpa for benchmarking.

Is foundit the same as Monster India?

Yes. Monster India was renamed foundit in 2022; the site is foundit.in and the data is the same board.

Does it cover foundit Gulf, Singapore, Malaysia or Indonesia?

Not yet; this Actor covers foundit.in (India, including remote and the occasional overseas posting listed there). Open an issue if you need another region.

Why does a city return remote jobs only?

foundit answers an unknown city name with its remote jobs. The Actor drops those rows, charges nothing and tells you in the status message; use the spelling foundit uses (Bangalore, Delhi, Mumbai, Hyderabad, Chennai, Pune, Kolkata, Ahmedabad, Remote).

Do I need a proxy or login?

No.
