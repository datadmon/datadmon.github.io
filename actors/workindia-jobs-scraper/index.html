WorkIndia jobs with salary as JSON API

WorkIndia Jobs Scraper is a pay-per-record Apify Actor by Daemon Data that returns WorkIndia (workindia.in) India jobs with monthly salary range, city, locality, PIN, category and full description as JSON, CSV or Excel. It costs $0.0008 per job with the default options ($0.80 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-06; this build does not run paid example searches.

{
  "cities": [
    "Mumbai"
  ],
  "maxResults": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~workindia-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cities": ["Mumbai"], "maxResults": 50}'

Python: ApifyClient(token).actor("data_daemon/workindia-jobs-scraper").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/workindia-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
citiesarrayCity names, e.g. Mumbai, Delhi, Bengaluru (or Bangalore), Pune, Hyderabad. Empty = all cities. WorkIndia files Gurgaon, Noida, Greater Noida, Ghaziabad and Faridabad under Delhi and Navi Mumbai under Mumbai; those names select the matching localities. Matched before any job page is opened.
keywordsarrayWords matched against the job title, e.g. delivery, telecaller, accountant, driver, sales. Empty = all jobs. Matched before any job page is opened.
categoriesarrayWorkIndia's job category, e.g. Delivery, Telecalling, Sales, Back Office, Accounts, Driver. Checked on the job page; others are not charged.
minSalaryintegerKeep jobs whose maximum monthly salary is at least this.
postedWithinDaysintegerKeep jobs posted in the last N days (datePosted).
includeDescriptionbooleanFull job description and responsibilities text.
maxResultsintegerStop after this many saved jobs (default 50, about $0.04). 0 = no cap: the whole current board is about 15,000 jobs and takes about an hour (the default run timeout is 2 hours).
onlyNewSinceLastRunbooleanRemember delivered job ids in a key-value store named workindia-jobs-state and skip them next time (not charged).
stateNamestringName of the only-new memory. By default it follows cities, keywords and categories.
skipIdsarrayWorkIndia job ids you already have (the number at the end of the job URL). Neither saved nor charged.

Price

$0.0008 per job ($0.80 per 1,000); $0.001 per run. List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.

Job$0.0008$0.80One WorkIndia job saved to the dataset with employer, location, monthly salary range, requirements and full description. Jobs left out by filters, only-new mode or skipIds are never charged.

Cost example: 50 jobs with default options cost $0.041, including any start fee. This is an illustrative record count; set explicit row and total-charge caps for your run. Apify's free plan includes $5 of usage a month, about 6,250 jobs before start fees; the Actor's own compute is included in the per-record price, and records skipped by filters, de-duplication or only-new mode are not charged.
