OnlineJobs.ph jobs with wages as JSON API

OnlineJobs.ph Scraper is a pay-per-record Apify Actor by Daemon Data that returns OnlineJobs.ph Philippine remote and virtual-assistant jobs with wage parsed to min/max/currency/period, hours per week, skills and full description as JSON, CSV or Excel. It costs $0.0008 per job with the default options ($0.80 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-13; this build does not run paid example searches.

{
  "keywords": [
    "virtual assistant"
  ],
  "maxResults": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~onlinejobs-ph-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["virtual assistant"], "maxResults": 50}'

Python: ApifyClient(token).actor("data_daemon/onlinejobs-ph-scraper").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/onlinejobs-ph-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
keywordsarrayJob searches as typed on OnlineJobs.ph, e.g. virtual assistant, bookkeeper, video editor. Each search returns its newest 285 matches at most (weeks of history for a niche role). Leave empty for the newest jobs on the whole board (about one day, ~270 jobs).
workTypesarrayKeep only these types. Jobs marked "Any" by the employer match every type. Empty = all.
skillsarrayKeep only jobs tagged with one of these OnlineJobs.ph skills, e.g. Shopify, Bookkeeping, Video Editing (case-insensitive, partial match). Empty = no skill filter.
postedWithinDaysintegerKeep jobs posted in the last N days (postedAt). Results are newest first, so reading stops at the first older job.
includeDetailsbooleanAdds the full job description, hours per week, date updated and employer id from the job page (one extra request per job). Off: listing data only (title, wage, type, posting time, skill tags, a short excerpt), faster.
maxResultsintegerStop after this many saved jobs (default 50, about $0.04). 0 = no cap: up to 285 jobs per search.
onlyNewSinceLastRunbooleanRemember delivered job ids in a key-value store named onlinejobs-ph-state and skip them next time (not charged). Schedule it daily with no keywords for a full-board feed.
stateNamestringName of the only-new memory. By default it follows the keywords, work types and skills.
skipIdsarrayOnlineJobs.ph job ids you already have (the number at the end of the job URL). Neither saved nor charged.

$0.0008 per job ($0.80 per 1,000); $0.001 per run. List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.
