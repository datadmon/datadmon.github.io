Podcast Transcript API – Audio Transcription, Speech to Text data API

Podcast Transcript API is a pay-per-record Apify Actor by Daemon Data that returns Podcast transcripts from a show name, an Apple Podcasts or Spotify link, an RSS feed or any audio/video file link: full text, timestamps, SRT and episode details as JSON. Whisper runs inside the Actor, no API key. $0.0025 per audio minute; failed links and silent files are free. as JSON, CSV or Excel. It costs $0.0025 per audio minute (fast model) with the default options ($2.50 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Why teams use it

  • Search and quote podcasts: full text of every episode of a show, with timestamps to jump to the passage.
  • Summaries, show notes and newsletters: feed the transcript to an LLM instead of listening to two hours of audio.
  • Monitor what is said about a brand, a person or a topic: follow a list of shows on a schedule and get each new episode once.
  • RAG and AI agents: clean text with episode facts attached, ready to be chunked and indexed.
  • Research and media analysis: a show's back catalogue for a date range as one dataset.
  • Subtitles: SRT for an interview, a webinar recording or a video file.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-26; this build does not run paid example searches.

{
  "podcasts": [
    "https://podcasts.apple.com/us/podcast/up-first-from-npr/id1222114325"
  ],
  "episodesPerPodcast": 1,
  "maxMinutesPerEpisode": 5,
  "model": "fast"
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~podcast-transcript-api/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"podcasts": ["https://podcasts.apple.com/us/podcast/up-first-from-npr/id1222114325"], "episodesPerPodcast": 1, "maxMinutesPerEpisode": 5, "model": "fast"}'

Python: ApifyClient(token).actor("data_daemon/podcast-transcript-api").call(run_input=...). Python, Node.js and n8n calling instructions. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/podcast-transcript-api with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
podcastsarrayOne per line: a podcast name (for example Lex Fridman Podcast), an Apple Podcasts link (show or episode), a Spotify link (show or episode) or an RSS feed URL. A show gives its newest episodes; a link to one episode gives that episode. Spotify links work for shows that also have a public feed (most do; Spotify-only shows do not).
audioUrlsarrayDirect links to files: MP3, M4A, WAV, FLAC, OGG, MP4, MOV, WEBM, MKV and similar, up to 1.5 GB each. The link must open without a login. Page links (YouTube, a website) are not files and are returned with a note, not charged.
episodesPerPodcastintegerHow many of each show's newest episodes to transcribe (after the date and title filters). Default 1. One run reads at most 500 episodes and files in all.
maxMinutesPerEpisodeintegerTranscribe only the first N minutes of each episode or file. 0 = the whole episode (up to 6 hours). You pay for the minutes transcribed.
modelstringFast: Whisper tiny, $0.0025 per audio minute, good for clear speech, search and summaries. Accurate: Whisper base, $0.005 per audio minute, fewer mistakes on names, accents and noisy audio; takes about twice as long.
languagestringauto detects the spoken language from the start of the audio. Or give a language code (en, es, de, fr, pt, hi, ja, ...; en-US is read as en) when you know it: this is safer for audio that starts with music.
usePublisherTranscriptbooleanSome shows publish a transcript with each episode (Podcasting 2.0). It is usually better than any automatic one and costs a flat $0.005 per episode instead of the per-minute price. Turn off to always transcribe the audio.
publishedAfterstringOnly episodes published on or after this date: YYYY-MM-DD, or a number of days such as 7 days.
publishedBeforestringOnly episodes published on or before this date (YYYY-MM-DD). With Published on or after it selects a range, for example one month of a show's back catalogue.
titleContainsstringOnly episodes whose title contains these words, for example a guest's name.
includeSegmentsbooleanAdd the list of segments with start and end seconds to each row. Turn off for a smaller row with only the text.
includeSrtbooleanAdd the transcript as an SRT subtitle text to each row.
onlyNewSinceLastRunbooleanRemember the episodes delivered and skip them on the next run with the same podcasts: schedule the Actor daily and each new episode is transcribed once. Episodes delivered before are not charged.
stateNamestringOptional name for the memory of delivered episodes. Use different names for schedules that should not share it. Without a name the list of podcasts and files identifies it.
countrystringTwo-letter country of Apple's podcast directory used to look up a podcast by name (US, GB, DE, IN, BR, ...). Default US. Links and feeds do not need it.

Questions buyers ask

How accurate is it?

It uses OpenAI's open Whisper models (tiny and base, the English-only versions for English audio), which are the small, fast members of the family. On clear speech the text is easy to read and reliable for search and summaries; you will see occasional wrong names and homophones, more so with the fast model. It does not label speakers, and a file with no speech in 20 minutes is left at that point. If the show publishes its own transcript, you get that one, which is normally better than any automatic transcript.

Which languages work?

About 100, the languages Whisper knows. Quality is best for English, Spanish, German, French, Portuguese, Italian, Dutch, Japanese and other widely spoken languages, and weaker for small ones; prefer the accurate model outside English.

Can it transcribe YouTube videos?

No. It reads podcast feeds and direct file links. A YouTube or web page link is returned with a note and not charged.

Is my audio sent to a third party?

No. The file is downloaded into the run, transcribed there and deleted when the episode is done. The transcript is stored in your run's dataset.

Can I schedule it?

Yes. Turn on onlyNewSinceLastRun, create a schedule, and each run delivers only episodes that were not delivered before. Use stateName when two schedules should keep separate memories.

Can I call it from code or from an AI agent?

Yes: the Apify API, the Python and JavaScript clients, and Apify's MCP server all run it like any other Actor and read the dataset.

Something is wrong or missing

Open an issue on the Actor's Issues tab with the run ID or the link that failed.
