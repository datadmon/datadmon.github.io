HKEX announcements, director dealings and CCASS shareholding as JSON API

HKEX News API is a pay-per-record Apify Actor by Daemon Data that returns Hong Kong Exchange (HKEX) data as JSON: HKEXnews announcements with category, title and document link; director and substantial-shareholder dealings (disclosure of interests); CCASS shareholding by participant. Stock-code watchlists, only-new feed. $3 per 1,000 filings, $1 per 1,000 CCASS rows. as JSON, CSV or Excel. It costs $0.003 per announcement or dealing row with the default options ($3.00 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Why teams use it

  • Rows, not pages. The three sources are a search form, a set of paged tables and a form that posts back. This Actor returns them as JSON with ISO dates in Hong Kong time, numbers as numbers, stock codes with leading zeros and stable field names.
  • A feed that delivers each row once. With onlyNew the Actor remembers what it delivered. Schedule it with daysBack: 7: a notice filed days after its event is still picked up, and nothing is delivered or charged twice.
  • Filter before you pay. stockCodes, headlineCategories and keywords are applied before rows are saved. Exact category names are filtered at the source, so a year of one category is a small run.
  • A whole day, complete. A busy day is read in one request and the row count is checked against the total HKEXnews reports (687 of 687 on 13 November 2026).
  • Dealings you can sort. (L), (S) and (P) become long, short and lending-pool fields; reason codes come with HKEX's wording and a plain transactionType (increase, decrease, short increase ...).
  • CCASS changes in one call. compareDays puts today's and the earlier holding on the same row.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-26; this build does not run paid example searches.

{
  "reports": [
    "announcements"
  ],
  "daysBack": 7,
  "maxItems": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~hkex-news-filings/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reports": ["announcements"], "daysBack": 7, "maxItems": 50}'

Python: ApifyClient(token).actor("data_daemon/hkex-news-filings").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/hkex-news-filings with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
reportsarrayWhich HKEX feeds to read. Each row carries its reportType. announcements (default): listed-company announcements, circulars, results, next-day disclosure returns and other documents from the HKEXnews title search, with stock codes, headline category and document link (687 entries on Friday 13 November 2026). directorDealings: disclosure-of-interests notices filed by directors, chief executives and substantial shareholders (who, shares bought or sold, average price, holding and percent afterwards; 626 notices for the event days 9-13 November 2026). ccassHoldings: CCASS participant shareholding of each stock in stockCodes on one day (which broker or custodian holds how many shares and what percent of the issued shares; 416 participants for Tencent on 13 November 2026).
stockCodesarrayHKEX stock codes to keep, with or without leading zeros: 00700, 700, 5, 09988. The spellings other tools use (0700.HK, HKEX:700) and HKEXnews short names (TENCENT) work too. Empty = the whole market for announcements and dealings. Required for ccassHoldings, which is searched one stock at a time. With stock codes, announcements and dealings are read per company, so a year of history for a watchlist is a small run.
headlineCategoriesarrayKeep announcements of these HKEX headline categories. Exact names are filtered by HKEXnews itself, which makes long histories cheap: tier one such as Announcements and Notices, Circulars, Financial Statements/ESG Information, Next Day Disclosure Returns, Monthly Returns, Listing Documents, or a subcategory such as Final Results, Interim Results, Profit Warning, Inside Information, Dividend or Distribution, Share Buyback, Trading Halt. Any other text is matched as words in the category of each row. Empty = everything HKEXnews lists, including fund trading information and structured-product notices.
keywordsarrayKeep rows that contain one of these words (case-insensitive). Announcements: title, stock name and category (placing, privatisation, profit warning). Dealings: company, holder name and reason (BlackRock, purchased). CCASS: participant name or ID (HSBC, C00019). Empty = all.
daysBackintegerFor announcements and dealings: how many days before today (Hong Kong time) to read, today included. 0 = today only, 7 (default) = today and the seven days before. Ignored when From date is set. Dealings are searched by the date of the event, and a notice can be filed some days after it: read at least 5 days back in a daily feed.
fromDatestringFirst day (YYYY-MM-DD, Hong Kong time) for announcements and dealings. Use with To date for a backfill; the week of 9-13 November 2026 had 3,283 entries.
toDatestringLast day (YYYY-MM-DD, Hong Kong time). Empty = today.
languagestringHKEXnews files the English and the Chinese version of a document as separate entries with their own ids. en (default) reads the English entries, zh the Chinese ones (titles and categories in Chinese), both reads both and marks each row with its language.
includeDetailsbooleanFor directorDealings: open the notice page of every delivered row and add the stock code, the share class, the number of issued shares, the holding and percent before the event, the change, the capacity and the highest price. One more request per notice (about three seconds each), so it is off by default. Not needed for the stock code when stockCodes is set: those rows carry it already.
holdingDatestringFor ccassHoldings: the day whose holdings to read (YYYY-MM-DD). Empty = the latest day CCASS serves (the day before today). CCASS serves the past 12 months; for a Sunday or public holiday it answers with the day before, and the rows say which day they are.
topParticipantsintegerFor ccassHoldings: keep the largest N participants of each stock, by shares held. Default 50. 0 = every participant (416 rows for Tencent on 13 November 2026). Each stock also returns one summary row with the totals.
minPercentstringFor ccassHoldings: keep participants that hold at least this percent of the issued shares, for example 1 or 0.5. Empty or 0 = no minimum.
compareDaysintegerFor ccassHoldings: also read the holdings N days before the holding date and add previousShares, sharesChange and percentOfIssuedChange to every row (who added, who reduced). One more request per stock. 0 (default) = no comparison.
maxItemsintegerStop announcements and dealings after this many rows each, newest first. 0 = no limit. Each of these rows costs $0.003, so the default 50 rows cost $0.15. CCASS rows are limited by Participants per stock instead.
onlyNewbooleanRemember what was delivered and return only rows that are new since the last run with the same state name. Rows already delivered are skipped and not charged again, so a scheduled run with Days back 7 never misses a late notice and never bills one twice. For CCASS a day's holdings of a stock are delivered once.
stateNamestringName of the only-new memory. Use a different name for each independent feed (for example one per watchlist). Letters, digits, dash and underscore.
