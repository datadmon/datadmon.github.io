Company Domain Finder – Name to Website & LinkedIn ($0.60/1K) data API

Company Domain Finder is a pay-per-record Apify Actor by Daemon Data that returns Turn a list of company names into official domains and websites, with a confidence score, the company's LinkedIn page and social links, logo and alternatives. Bulk, no API key. $0.60 per 1,000 companies found; names without a match are free. as JSON, CSV or Excel. It costs $0.0006 per company found with the default options ($0.60 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Why teams use it

  • Enrich a CRM or a lead list that has company names but no websites, before an email finder or an enrichment tool that needs a domain.
  • Clean up a spreadsheet of accounts: one canonical domain per company, with duplicates visible.
  • Join datasets: job postings, tenders, filings or review data that carry a company name can be joined to anything keyed by domain.
  • Feed an AI agent: "what is the website of X" answered with a confidence value and alternatives instead of a guess.
  • Company LinkedIn URL from a name, without visiting LinkedIn: the link is read from the company's own homepage.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-22; this build does not run paid example searches.

{
  "companyNames": [
    "Stripe",
    "Siemens",
    "Tata Consultancy Services",
    "Hetzner",
    "Brompton Bicycle"
  ],
  "verifyWebsite": true
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~company-domain-finder/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"companyNames": ["Stripe", "Siemens", "Tata Consultancy Services", "Hetzner", "Brompton Bicycle"], "verifyWebsite": true}'

Python: ApifyClient(token).actor("data_daemon/company-domain-finder").call(run_input=...). Python, Node.js and n8n calling instructions. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/company-domain-finder with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
companyNamesarrayOne company per line, up to 10,000 per run, for example Stripe, Siemens AG or Tata Consultancy Services. Legal suffixes (Inc, Ltd, GmbH) are ignored when matching. Duplicates are looked up once.
verifyWebsitebooleanOpen each found domain's homepage once: HTTP status, final URL after redirects, page title, logo and social links. Turn it off for domains only, which is faster.
extractCompanyLinkedInbooleanRead the links to the company's own pages on LinkedIn, X, Facebook, Instagram, YouTube and GitHub from its homepage. Needs Open the website. LinkedIn itself is not visited.
minConfidencestringHow close the matched company's name must be to yours, from 0.3 (loose) to 1 (same name after removing legal suffixes). Default 0.6. Below the threshold a row comes back with found false, the best candidate in note, and no charge.

Questions buyers ask

How accurate is it?

On our test list of 30 names (22 November 2026: well-known and mid-size companies from ten countries, several written with legal suffixes), all 23 names with one known answer resolved to the expected domain. Of three made-up or ambiguous names, two were returned as not found and one ("Acme") matched "Acme Tools" at confidence 0.6. The list is small and leans towards known companies: small local businesses that appear in neither source are returned as not found.

Where does the data come from?

A public company suggest index, Wikidata's "official website" statements, and each company's own homepage. LinkedIn and other networks are not visited; their links are read from the company's homepage.

Does it return people or email addresses?

No. It returns company-level data only.
