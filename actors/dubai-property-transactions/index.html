Dubai DLD transactions: pay-per-record data API

Dubai DLD Property Transactions API – Sold Prices, Price/Sqm is a pay-per-record data API on Apify that returns Dubai Land Department sales, mortgages and gifts with AED value and price/sqm as JSON, CSV or Excel. It costs $0.001 per transaction ($1.00 per 1,000) and runs on a schedule, from code, or from an AI assistant through MCP.

Run it on Apify   Listing as plain text for agents

What you get

Actual registered sold prices for Dubai, as a daily data feed. This Actor reads the Dubai Land Department's own open-data transaction register and returns every sale, off-plan sale, mortgage and gift with the transaction date, value in AED, price per sqm (computed), area, project and master project, property type and sub-type, rooms, parking, size, off-plan and freehold flags, and the nearest metro, mall and landmark.

Why use it

  • Registered prices, not asking prices. Listing portals show what sellers want; DLD shows what buyers actually paid.
  • Complete. A typical week has 3,000–6,000 transactions; the Actor pages through all of them, 500 at a time.
  • Analysis-ready. Numeric AED values and areas, ISO dates, boolean off-plan/freehold flags, pricePerSqmAed precomputed, optional Arabic names.
  • Pre-registration vs completed sale. The procedure field separates developer pre-registrations (Sell - Pre registration) from completed sales (Sale, Delayed Sell), and mortgage registrations from modifications.
  • Open data, no personal data. Published by the Dubai Land Department for reuse; no owner names or contacts are included.
  • From an AI assistant:* add the MCP connector https://mcp.apify.com/?tools=data_daemon/dubai-property-transactions in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

How to call it

One HTTP call starts a run, waits for it and returns the records. Replace the token with yours from console.apify.com.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~dubai-property-transactions/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"transactionGroup": "sales", "maxItems": 500}'

From an AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/dubai-property-transactions with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code, then ask for the data in plain words. Python, Node.js and n8n: python/dubai-property-transactions.py, node/dubai-property-transactions.mjs, n8n/dubai-property-transactions.json.

Input fields

FieldTypeMeaning
fromDatestringStart of the transaction date range, YYYY-MM-DD (DD/MM/YYYY also accepted). Leave empty to use Days back instead, so a scheduled run never needs a date edit. An invalid date is ignored with a warning.
toDatestringEnd of the transaction date range, YYYY-MM-DD. Defaults to today (UTC).
daysBackintegerUsed when From date is empty: fetch the last N days up to To date (or today). Default 7, minimum 1, maximum 365; values outside that range are clamped. Set 1 for a daily scheduled feed. All transactions run about 600 rows ($0.60) per working day and 4,000 ($4) per week; DLD registers nothing on weekends, so a weekend run returns 0 rows and costs nothing.
transactionGroupstringFilter by DLD transaction group: all, sales, mortgages or gifts. Weekly volume in Oct 2026: all about 4,000 rows ($4.00), sales about 2,600 ($2.60), mortgages about 1,300 ($1.30), gifts about 160 ($0.16).
offPlanstringOff-plan (developer pre-registration) vs completed properties: all, offplan or ready. Of about 2,600 weekly sales, roughly 1,650 are off-plan and 950 ready.
freeholdstringFreehold vs non-freehold tenure: all, freehold or nonfreehold.
usagestringProperty usage: all, residential or commercial. Of about 2,600 weekly sales, roughly 2,500 are residential and 70 commercial.
propertyTypestringProperty type: all, unit (apartments and villa units), building or land. Land plots are about 220 of the 2,600 weekly sales.
includeArabicbooleanAdd an arabic object with the Arabic names for area, project, procedure etc. No extra charge.
maxItemsintegerStop after this many transactions (0 = all in range). Each transaction costs $0.001, so the default 200 = $0.20 and 2,000 = $2.00. A typical week has 3,000-6,000 transactions.
sortstringSort order by DLD transaction number: TRANSACTION_NUMBER_ASC or TRANSACTION_NUMBER_DESC. Matters only when maxItems cuts the range short.
areaIdstringAdvanced: DLD internal area id, passed through to the gateway. The transactions feed returns areaId 0 on every row and, as of October 2026, 0 rows for any id sent here, so ids cannot be looked up from the output and this filter is not usable. Leave empty and filter on the area name in the results.

Questions and answers

How much does it cost to get Dubai property transactions?

$0.001 per transaction. A full week of all DLD transactions (about 4,100 rows) costs about $4.10; a week of sales alone about $2.60.

Is this the official DLD data?

Yes. It reads the Dubai Land Department's open-data transactions service, the same register that paid DLD data products resell.

Can I filter by area or off-plan?

Off-plan vs ready, sales / mortgages / gifts, freehold, usage and property type are input filters. For areas, filter the output on the area and project names: DLD's area-id parameter returns no rows and areaId is 0 on every row, so that field is hidden under Advanced.

Does it include price per square metre?

Yes, pricePerSqmAed is computed from the transaction value and the actual area.

Can I run it every day without editing dates?

Yes. Leave fromDate empty and set daysBack to 1; the window moves with the run date.
