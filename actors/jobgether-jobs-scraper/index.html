Jobgether remote jobs with salary, skills and apply link as JSON API

Jobgether Scraper is a pay-per-record Apify Actor by Daemon Data that returns Scrape Jobgether remote jobs by keyword, skill, country or region, employment type, seniority, salary and date. Each job has the company, where it is open, salary, skills, posting time and the employer's apply link; full description on request. Only-new mode for daily feeds. No login, no proxy. as JSON, CSV or Excel. It costs $0.0008 per job with the default options ($0.80 per 1,000); no login to the source site and no proxy or browser to set up on your side, and the same input runs from the Apify console, one REST call, Python, Node.js, n8n or an AI assistant through MCP.

Input and how to call it

Example input. Fields and pricing were checked against the public listing on 2026-11-20; this build does not run paid example searches.

{
  "keywords": [
    "python"
  ],
  "locations": [
    "Europe"
  ],
  "maxResults": 50
}

One HTTP call starts a run, waits for it and returns the records (token from console.apify.com):

curl -X POST "https://api.apify.com/v2/acts/data_daemon~jobgether-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["python"], "locations": ["Europe"], "maxResults": 50}'

Python: ApifyClient(token).actor("data_daemon/jobgether-jobs-scraper").call(run_input=...). Python example · Node.js example · n8n workflow. AI assistant (MCP): add the remote server https://mcp.apify.com/?tools=data_daemon/jobgether-jobs-scraper with header Authorization: Bearer YOUR_APIFY_TOKEN in Claude, ChatGPT, Cursor or VS Code and ask for the data in plain words.

All input fields

FieldTypeMeaning
keywordsarrayJob titles or words, one search each (e.g. python, data engineer, customer success). Uses Jobgether's own keyword search. Empty = all jobs, newest first.
locationsarrayWhere the candidate lives: a country (Germany, United States, Brazil), a region (Europe, Latin America, APAC), a US state (Texas) or Worldwide. One search per entry. Jobgether returns the jobs open to people there, including jobs open to the whole region or to anyone. Names are looked up in Jobgether's location list; unknown ones are skipped and named in the status message. Empty = everywhere.
employmentTypesarrayOnly jobs of these employment types (Jobgether's contract filter). Empty = all.
experienceLevelsarrayOnly jobs of these seniority levels (Jobgether's experience filter). Jobs without a level are left out when this is set. Empty = all.
skillsarrayJobs tagged with a skill, one search each (e.g. Python, Salesforce, Figma). Wider than a keyword: it matches the skill tags Jobgether puts on each job, not only the title. Names are looked up in Jobgether's skill list.
companiesarrayOnly jobs at these employers (e.g. GitLab, Automattic). Names are looked up in Jobgether's company list; unknown ones are skipped and named in the status message.
minSalaryintegerOnly jobs whose shown salary range starts at or above this yearly amount, in the job's own currency (e.g. 100000). Jobs without a salary are left out when this is set.
salaryCurrencystringOnly jobs whose salary is shown in this currency, e.g. USD, EUR, GBP, CAD. Jobs without a salary are left out when this is set. Left-out jobs are not charged.
postedWithinDaysintegerOnly jobs added to Jobgether in the last N days. Reading stops once a page is older than the window.
sortBystringNewest first (default) suits feeds and alerts. Relevance is the order Jobgether shows by default.
includeDescriptionbooleanOn: opens each job page (one extra request per job, about 0.6 seconds each) for the full description as text and the date the posting is valid through, at no extra charge. Off (default): the list fields only, 50 jobs per request.
includeRequirementsbooleanOn: one more request per job for the qualifications and responsibilities as lists, the employer's industries, required languages, soft skills and the complete skill list, at no extra charge. Jobgether allows 30 such requests a minute, so this adds about 2 seconds per job. Off by default.
maxResultsintegerStop after this many jobs in total. With several searches the cap is shared evenly between them. 0 = no cap (the run's maximum cost still applies).
onlyNewSinceLastRunbooleanOn: deliver only jobs that an earlier run with the same stateName (or the same search) has not delivered, and skip the rest without charging. Off (default): return every matching job.
stateNamestringOptional name for the only-new memory, e.g. python-europe. Runs with the same name share one memory. Empty = derived from the keywords, skills, locations, companies, employment types and experience levels.
skipJobIdsarrayJobgether job IDs you already have (the id field, 24 characters); they are skipped and not charged.

Price

$0.0008 per job ($0.80 per 1,000); $0.001 per run. List prices for Apify Free and Starter plans; Scale and Business plans pay 15% to 30% less.
