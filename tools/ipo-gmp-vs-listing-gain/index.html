Method, definitions and limits

Source: InvestorGain’s GMP Performance Tracker, report 377, calendar year 2026, both segments, all pages. 303 source rows retrieved; 303 completed 2026 listings with numeric GMP and prices included; 0 excluded. This covers every row in that source report at collection, rather than an independently reconciled exchange census. Its mainboard category also includes REIT/InvIT and property-trust issues; we retain that classification.

“Last GMP” means the final GMP reported in this historical performance table, interpreted as the pre-listing premium. It is separate from live GMP, the historical maximum premium and current trading prices. Individual pre-listing quote timestamps are not supplied: this is a retrospective source comparison, not independently timestamped forecasts. A zero is retained as zero; it may mean no premium was quoted, rather than a liquid trade at par. Missing quotes are never converted to zero.

  • GMP % = 100 × last GMP / issue price, rounded to two decimals.
  • Listing gain % = 100 × (listing-day opening price / issue price − 1), using the report’s two-decimal gain, verified against the prices. It is not the first-day closing return or the latest traded price.
  • Signed error = listing gain % − GMP %. Mean absolute miss averages the absolute errors. Within ±5/±10 uses inclusive boundaries. Band boundaries are also explicit: e.g. above 10% through 25%.
  • No weighting by issue size or subscription. The sample is descriptive and contains no confidence interval or future performance guarantee. Small filtered groups can be misleading; always quote n.

Source checks: All 294 overlapping rows from the October 28 study retain the same GMP, issue price, listing price, gain, category and listing date. How to refresh it with an IPO GMP API

The India IPO Tracker Actor returns the same gmpPerformance report as JSON, CSV or Excel, plus separate live GMP, calendar and subscription reports. Select gmpPerformance, year 2026, category all, and enough rows for the complete source report. Pagination matters: do not treat a capped partial run as the full year. At the checked $3 per 1,000 report rows, 303 rows have a list value of $0.909; platform terms and plan discounts may vary. This static download is free.

curl -X POST 'https://api.apify.com/v2/acts/data_daemon~india-ipo-tracker/run-sync-get-dataset-items?timeout=120&maxTotalChargeUsd=2' \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"reports":["gmpPerformance"],"year":2026,"category":"all","maxItems":500,"includeIpoDetails":false}'

The example is capped at 500 rows and a $2 total charge; raise both deliberately if a later year-to-date report exceeds the row cap. Inspect the run status, report count and source coverage before replacing your dataset. To compute a row’s error, subtract gmpPercent from listingGainPercent. The local site maintainer can freeze a complete Actor JSON export with python scripts/refresh_ipo_explorer.py --input performance.json, then rebuild. Refreshes are manual; this page has no trackers, external scripts or automatic paid calls.
