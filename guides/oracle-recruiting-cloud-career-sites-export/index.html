Oracle Recruiting Cloud career sites: how to export every job of an employer as JSON

Thousands of large employers run their careers page on Oracle Recruiting Cloud, part of Oracle Fusion Cloud HCM: banks, hotel groups, hospitals, universities, manufacturers and governments. Oracle describes the product as helping "organizations enhance the candidate experience, grow talent pools, drive internal mobility, and streamline the hiring process" and lets them "create branded career sites and tailored content for candidates" (oracle.com, accessed 21 October 2026); those branded career sites are the pages this guide is about. These jobs are often posted nowhere else, so job boards, aggregators, talent-intelligence teams and B2B sales teams tracking hiring signals need to read the career sites directly. This guide explains how to recognise such a site, what it exposes and how to export it.

How to recognise an Oracle Recruiting Cloud career site

The URL contains oraclecloud.com/hcmUI/CandidateExperience, for example https://jpmc.fa.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001. The first part is the employer's tenant, the sites/CX... part is the career site number (an employer may run several, for example one per region or one for internal candidates). Every such site is backed by the same JSON endpoints, which is why one API can read any of them.

What each job record contains

Requisition id (stable across runs), title, posting date, locations, job family and function, workplace type where the employer tags it (remote, hybrid, on-site), the direct apply URL, and with details on: the full description, qualifications, responsibilities, skills and the employer's custom fields. Posting-date filters use Oracle's own two buckets (last 7 days, last 30 days). Keyword and location filters behave like the career site's own search box.

How to export

Paste any URL from the site, even a single job's URL or just the host name; the API works out the tenant and the employer's active site, and lists the sites that exist if the number is wrong.

curl -X POST "https://api.apify.com/v2/acts/data_daemon~oracle-hcm-jobs-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"careerSiteUrls": ["https://jpmc.fa.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001"], "location": "India", "postedWithinDays": 7, "includeDetails": true, "maxJobsPerSite": 200}'

Several employers go in one list; the ready-made example "Jobs from several Oracle Recruiting Cloud career sites" reads Oracle's and Marriott's sites in one run (80 jobs found in 15 seconds on 21 October 2026). For a daily hiring-signal feed, switch on onlyNewSinceLastRun: the API remembers delivered requisition ids per search and later runs return only new postings, without charging for the rest.

What it costs

$2 per 1,000 jobs plus $2 per 1,000 full detail records, so a 500-job site with details costs $2. Apify's free plan ($5 a month) covers about 1,250 jobs with details. From 2 November 2026 the listing moves to $2 per 1,000 jobs with the details included plus $0.001 per run.

Questions and answers

Is there a public API for Oracle Recruiting Cloud job postings?

Yes, in practice: career sites load their jobs from unauthenticated candidate-experience endpoints (recruitingCEJobRequisitions, recruitingCEJobRequisitionDetails, recruitingCESites). A wrong site number does not fail: on 29 October 2026 Ford's tenant answered CX_999 with its default site's 915 jobs and Oracle's tenant answered every site number with the same 2,710. Endpoints, parameters and a Python script: Oracle Recruiting Cloud jobs API.

Does this work for Taleo, Workday, Greenhouse or SuccessFactors sites?

No. It reads Oracle Recruiting Cloud sites only (oraclecloud.com/hcmUI/CandidateExperience). Oracle Taleo is a different product with different pages.

Can I get only new requisitions every morning?

Yes. Save the input as a task with onlyNewSinceLastRun: true, schedule it daily, and connect the task to Slack, Google Sheets or a webhook. Skipped jobs are not charged.

How do I find the right site number?

Paste any URL from the employer's careers page. If it has no site number, the API picks the employer's active public site; if the number is retired, the run log lists the sites on that tenant.

Does it include the employer's internal-only jobs?

No. It returns what the public career site shows to any visitor.
