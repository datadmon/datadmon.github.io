How to export every IIMJobs and Hirist job as a daily feed

Job aggregators, HR-tech products and hiring-market trackers usually need all of a job board, not the results of a few keywords. IIMJobs.com (MBA, finance, consulting, sales, HR and senior management roles in India) and Hirist.tech (India's tech-only board) have no public export. Since 26 October 2026 the IIMJobs Jobs Scraper and the Hirist.tech Jobs Scraper on Apify can deliver every listing a board shows in a date window, with the same fields as a keyword search.

How much there is

Measured on 26 October 2026 with the boards' own date filters:

Board Jobs posted in the last 7 days Last 30 days
IIMJobs 1,199 (about 170 a day) 4,602
Hirist 959 (about 140 a day) 4,448

Weekends are quieter: on a Sunday IIMJobs showed 17 new listings.

Step 1: run the full board once

Open the IIMJobs Jobs Scraper (or the Hirist.tech Jobs Scraper), switch on All jobs on the board and run it with:

{
  "allJobs": true,
  "postedWithinDays": 3,
  "onlyNewSinceLastRun": true,
  "stateName": "iimjobs-full-board"
}

The Actor ignores the keywords and walks every listing posted in the window, newest first. Each row has the job ID, title, company (with industry, size and AmbitionBox rating when available), locations, experience range, salary in LPA when disclosed, skills, applicant and view counts, posting time and the full job description. locations, the experience range and maxJobs still apply if you only want part of the board. Putting * in the keywords does the same as the switch.

Step 2: schedule it daily

Create a daily Apify schedule for the run (or a saved task with this input). Because of only-new mode, every later run returns only jobs the feed named by stateName has not delivered yet; repeats are skipped and not charged. We checked this on 26 October 2026: two back-to-back runs returned 15 and then 2 jobs, with no job delivered twice.

The date window counts calendar days in India time. Three days is a safe window for a daily schedule: it covers weekends and a run that starts late, and only-new mode removes the overlap.

Step 3: load it where you need it

The dataset of each run is available as JSON, CSV or Excel through the Apify API, so a database loader, an n8n or Make workflow, or a Google Sheets import can pick it up. Key on dedupKey (for example iimjobs:1741775), which is stable across runs and boards.

The same switch on Foundit and Instahyre

The Foundit Jobs Scraper and the Instahyre Jobs Scraper have the same All jobs on the board option. foundit (formerly Monster India) is far busier: 2,815 jobs posted in the last day on 26 October 2026, so its window defaults to one day. Instahyre had 12,724 open jobs and no date filter on the site, so follow it with only-new mode alone: the first run exports the open jobs (about 80 minutes at roughly three jobs a second; it stops cleanly before the run timeout and the next run continues), and later runs return only jobs that are new to the feed.

Costs and limits

Both Actors charge per job saved, with the price shown on their Apify pricing tabs; jobs skipped by only-new mode are free. A board-wide daily feed is roughly the number of new jobs per day from the table above. Set Maximum cost per run on the schedule if you want a hard ceiling; the run stops cleanly at that limit and says so.
