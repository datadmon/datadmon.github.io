India job board data compared: IIMJobs, Hirist, Foundit and Instahyre as APIs

India has no single job board. Recruiters post management roles on IIMJobs, software roles on Hirist, mass-market and syndicated roles on foundit (formerly Monster India) and product-company tech roles on Instahyre, and none of the four offers a public API. This guide compares the four boards as data sources: what each one covers, which fields it exposes, how fresh the postings are and what it costs to pull them through the Daemon Data APIs on Apify. All counts were measured on 18 to 21 October 2026 with the APIs themselves.

Freshness and feeds

IIMJobs, Hirist and foundit let the API ask the site for postings from the last N days, so a daily feed is cheap: a postedWithinDays: 1 run only touches new jobs. Instahyre's search has no date filter, so the API reads the posting date from each job page; in practice you run it in only-new mode, where the API remembers the job ids it has already delivered (in a key-value store in your own Apify account) and later runs return only what is new on the site. All four APIs share that only-new mode, the skipJobIds field and the same queries / locations input, so one pipeline can read all four boards.

Start an IIMJobs feed with a total cap

Use a distinct stateName for each saved search. This input delivers at most 50 jobs across all keywords, including the first run:

{
  "queries": ["product manager"],
  "postedWithinDays": 3,
  "onlyNewSinceLastRun": true,
  "stateName": "product-manager-daily",
  "maxJobsPerQuery": 50,
  "maxJobs": 50
}

At the FREE-tier list price, a 50-job run with descriptions costs at most $0.20 through 1 November 2026, then $0.101 including the start fee from 2 November. Later runs skip jobs already delivered; they may still return unseen jobs from the three-day window that exceeded a previous run's cap. A quiet search can return zero rows successfully.

Verified 22 October 2026: two consecutive runs on IIMJobs build 0.2.11, using this input shape with both caps reduced to 3, returned six distinct jobs. The second run reported three previously delivered jobs skipped. This verifies de-duplication, not a promise of three new postings between calls.

For code, use the Python and Node only-new-jobs examples or the n8n workflow for Google Sheets and Slack. For Console setup, save the input as a task and choose your timezone explicitly when adding a schedule.

Which board for which question

  • "Which companies are hiring finance or product leaders in India this week?" IIMJobs; filter on experience and read the applicant counts to see which mandates are crowded.
  • "What skills do Indian tech employers ask for, and what do they pay?" Hirist, which carries disclosed salary bands and skill tags on most rows; add Instahyre for startup roles with company headcount.
  • "Fresher or non-tech roles, or the largest possible volume." foundit, with its 2,900 new postings a day and fresher filters by experience band.
  • "Startups and product companies hiring engineers, by company size or remote." Instahyre, the only board here that publishes employer headcount and founding year and lets you filter by company size.

Questions and answers

Is there an official API for IIMJobs, Hirist, foundit or Instahyre?

No. None of the four publishes a public API. The Daemon Data APIs read the JSON endpoints and public pages the boards' own websites load, and expose them as Apify Actors with schedules, webhooks and only-new runs.

Can I get the same fields from all four boards in one pipeline?

Mostly. All four return id, title, company.name, locations, skills, postedAt, url and a description, and accept the same queries, locations, onlyNewSinceLastRun and skipJobIds input. Salary and applicant counts exist on IIMJobs, Hirist and foundit but not on Instahyre; company headcount exists on Instahyre and on Hirist/IIMJobs through AmbitionBox.

How fresh is the data?

As fresh as the run: each run reads the live site. The job-board APIs finish a 50-job run in well under a minute. IIMJobs, Hirist and foundit filter by posting date on the server; Instahyre needs only-new mode or a per-job date check.

Why are recruiter names missing?

The APIs leave out recruiter names and phone numbers on purpose, even where a board exposes them, and keep the recruiter's designation only where the board shows it to every visitor.
